# 四级灰度实施计划

本文供后续执行 Agent 使用。除非用户明确变更需求，否则不得修改物理前向、传播逻辑或共享结构。

## 1. 目标与停止边界

目标是在 23 个衍射通道中生成背景加三档细线：`1/3、2/3、1`。三档应肉眼明显分离，并且相同档位相对各自背景的有效亮度跨通道一致。各通道背景均值不要求一致，背景杂散不是首要优化目标，只要不淹没线条结构和灰度即可。

如果实现需要改变 `Φc = mc·dx + nc·dy → exp(iΦc) → FFT2 → |·|²`、为通道增加增益、改变 FFT 后的强度或引入不同通道的独立设计变量，立即停止并向用户报告不可行，不得继续。

## 2. Git 与回档

当前仓库的 `baseline-before-grayscale` 标签表示灰度实现前基线。执行 Agent 应：

1. 从该基线创建 `experiment/four-level-lines` 分支。
2. 每个阶段单独提交，禁止把目标生成、损失、指标和长时间实验混在一个提交中。
3. 建议提交顺序：
   - `test: lock physical forward regression`
   - `data: add three-line grayscale calibration target`
   - `feat: add four-level loss terms`
   - `feat: add grayscale metrics and visualizations`
   - `experiment: record selected line calibration result`
4. 回档可使用 `git switch main`，或从标签重新创建分支；不要使用会删除未提交工作的强制重置。
5. 不添加远程仓库，不上传 GitHub。

## 3. 阶段 A：冻结并验证物理前向

在修改损失前建立测试证据：

- 固定随机 `dx/dy`、固定 `(m,n)`，保存或计算基准远场数组。
- 验证新旧流程对同一 `dx/dy` 产生逐值一致的 `I_c`。
- 验证 Parseval/全平面总能量关系。
- 验证 23 通道仍共享同一组 `dx/dy`。
- 将前向表达式所在代码行列入审查清单，后续提交不得改动。

任何前向回归失败都必须停止实验。

## 4. 阶段 B：生成三线校准目标

新增独立的目标生成工具，不在训练时隐式改变目标：

- 输出 `23 × 500 × 500` 的四标签 MAT 数据。
- 所有通道使用相同几何结构，但仍对应原来的 23 组 `(m,n)`。
- 三条水平线等长、等粗、像素数一致且互不接触。
- 从上到下依次标记 `1/3、2/3、1`，其他区域为 `0`。
- 同时输出目标预览图和每个 `(channel, level)` 的像素数检查。
- 数据读取仅扩展为接受 `{0,1/3,2/3,1}`；不得改变传播计算。

建议首版使用长度约 200 像素、宽度 5 像素、竖直间隔约 60 像素的居中线段。若修改这些尺寸，必须在实验记录中说明。

## 5. 阶段 C：建立固定比例基线

先使用原有图像损失直接训练四级目标，作为对照组。保留相同随机种子、学习率、迭代轮数和设备配置，保存统一曝光图及原始数组。

该基线用于回答：原损失本身能否产生灰度，以及新增损失带来多少实际改善。

## 6. 阶段 D：只增加灰度相关损失

所有新损失只能读取冻结前向输出的原始 `I_c`。

### 6.1 公共有效亮度单位

```text
background[c] = mean(I[c] on background pixels)
S[c,l] = (mean(I[c] on level-l line) - background[c])
         / mean(I[c] on full plane)
```

固定前向下各通道全平面均值相同。扣除背景只用于定义图形的有效对比度，除法只用于统一数值尺度；两者都不修改前向输出或显示结果。

### 6.2 固定三档比例

令公共最高档尺度为 `Q`，目标响应为：

```text
[Q/3, 2Q/3, Q]
```

首轮不自由学习三个比例。`Q` 可由当轮所有通道最高档响应的公共统计量确定，但应停止梯度穿过该统计量，避免通过移动目标本身获取虚假低损失。原图像损失和目标区效率项必须保留，以防所有档位共同塌缩到低亮度。

### 6.3 损失组成

- `L_image`：保留现有图案/效率损失，负责形状和有效能量。
- `L_level`：所有 `(channel, level)` 接近公共 `Q/3、2Q/3、Q`。
- `L_cross`：逐灰度档缩小 `S[c,l]` 的跨通道 CV，约束同档有效亮度一致。
- `L_gap`：保证每个通道三档严格单调并具有最小间隔。
- `L_line_uniform`：降低同一条线内部的强度方差，避免斑驳。
- `L_visibility`：只保证最低灰度线高于本通道背景，避免图形被背景完全淹没。
- `L_worst`：约束最差的 `(channel, level)`，防止平均指标掩盖失败通道。

首轮不得加入背景均值一致性或背景均匀性损失，也不得把背景能量强行压到零。背景均匀性只在结果确实妨碍线条识别时，经过用户确认后作为弱损失单独实验。

## 7. 阶段 E：权重探索

采用由短到长的分级实验，避免直接进行大量长跑：

1. 小轮数检查梯度、数值稳定性、单调性和输出完整性。
2. 只扫描少量具有解释性的组合：先分别打开 `L_level/L_cross`、`L_gap`、线条均匀性与可见性项，再组合。
3. 淘汰出现档位塌缩、背景淹没线条、最差通道失效或只在逐通道归一化图上好看的组合。
4. 对少数候选使用相同随机种子执行中等轮数。
5. 选定一个候选后再执行正式轮数，并至少增加一个随机种子复核。

不要引入自动重试、动态兜底或复杂权重调度。若固定权重无法工作，应先报告各损失冲突，再决定是否尝试自适应灰度比例。

## 8. 输出与验收

每次实验至少保存：

- 最终 `dx/dy`、原始 `I_c` 和统一曝光图。
- `23 × 3` 非零灰度响应矩阵。
- 每档跨通道均值、CV、最大偏差和最差通道。
- 每通道三档比例误差、单调性和最小间隔。
- 每条线内部方差。
- 每通道背景均值、背景方差和背景高分位峰值；这些是观察指标，不是首轮优化目标。
- 原损失与所有新增分项损失的历史。
- 同一显示范围下的 23 通道结果总览，禁止用逐通道最大值归一化作为灰度证据。

首要人工验收是所有通道中三条线肉眼明显分开。数值指标用于定位失败通道和比较权重，不在探索前伪造一个未经验证的硬门槛。

## 9. 阶段 F：用户复核点

三线正式结果生成后暂停，由用户查看统一曝光图和最差通道。未经用户确认，不进入水果图实验。

## 10. 阶段 G：水果轮廓

用户确认三线结果后，再确定如何把每张水果轮廓分成三档线条。必须保持 23 个通道各自的水果图案，不得把所有通道替换成相同水果。先生成目标预览并让用户确认分档方式，再训练。

## 11. 暂不采用的复杂方案

- 自适应学习三个灰度比例：固定比例失败后才作为独立实验。
- 动态损失权重、课程学习或多阶段优化器：会扩大改动和解释难度，当前不采用。
- 重构前向为新模块：虽便于测试，但会触碰用户要求冻结的核心流程，当前仅增加外部回归测试。
- 独立通道增益、逐通道曝光校正、后处理灰度映射：违反物理约束，禁止采用。
