# 四级灰度实施计划

本文供后续执行 Agent 使用。除非用户明确变更需求，否则不得修改物理前向、传播逻辑或共享结构。

## 1. 目标与停止边界

目标是在 23 个衍射通道中生成背景加三档细线：`1/3、2/3、1`。三档应肉眼明显分离，并且相同档位相对各自背景的有效亮度跨通道一致。各通道背景均值不要求一致，但背景空间上应尽量一致，不得出现与目标线相似的明显横线或鬼影。

如果实现需要改变 `Φc = mc·dx + nc·dy → exp(iΦc) → FFT2 → |·|²`、为通道增加增益、改变 FFT 后的强度或引入不同通道的独立设计变量，立即停止并向用户报告不可行，不得继续。

## 2. Git 与回档

当前仓库的 `baseline-before-grayscale` 标签表示灰度实现前基线。执行 Agent 应：

1. 从该基线创建 `experiment/four-level-lines` 分支。
2. 每个阶段单独提交，禁止把目标生成、损失、指标和长时间实验混在一个提交中。
3. 建议提交顺序：
   - `test: lock physical forward regression`
   - `data: add three-line grayscale calibration target`
   - `feat: add four-level loss terms`
   - `feat: add grayscale metrics and visualizations`
   - `experiment: record selected line calibration result`
4. 回档可使用 `git switch main`，或从标签重新创建分支；不要使用会删除未提交工作的强制重置。
5. 不添加远程仓库，不上传 GitHub。

## 3. 阶段 A：冻结并验证物理前向

在修改损失前建立测试证据：

- 固定随机 `dx/dy`、固定 `(m,n)`，保存或计算基准远场数组。
- 验证新旧流程对同一 `dx/dy` 产生逐值一致的 `I_c`。
- 验证 Parseval/全平面总能量关系。
- 验证 23 通道仍共享同一组 `dx/dy`。
- 将前向表达式所在代码行列入审查清单，后续提交不得改动。

任何前向回归失败都必须停止实验。

## 4. 阶段 B：生成三线校准目标

新增独立的目标生成工具，不在训练时隐式改变目标：

- 输出 `23 × 500 × 500` 的四标签 MAT 数据。
- 所有通道使用相同几何结构，但仍对应原来的 23 组 `(m,n)`。
- 三条水平线等长、等粗、像素数一致且互不接触。
- 从上到下依次标记 `1/3、2/3、1`，其他区域为 `0`。
- 同时输出目标预览图和每个 `(channel, level)` 的像素数检查。
- 数据读取仅扩展为接受 `{0,1/3,2/3,1}`；不得改变传播计算。

建议首版使用长度约 200 像素、宽度 5 像素、竖直间隔约 60 像素的居中线段。若修改这些尺寸，必须在实验记录中说明。

## 5. 阶段 C：建立固定比例基线

先使用原有图像损失直接训练四级目标，作为对照组。保留相同随机种子、学习率、迭代轮数和设备配置，保存统一曝光图及原始数组。

该基线用于回答：原损失本身能否产生灰度，以及新增损失带来多少实际改善。

## 6. 阶段 D：只增加灰度相关损失

所有新损失只能读取冻结前向输出的原始 `I_c`。

### 6.1 公共有效亮度单位

```text
background[c] = mean(I[c] on background pixels)
S[c,l] = (mean(I[c] on level-l line) - background[c])
         / mean(I[c] on full plane)
```

固定前向下各通道全平面均值相同。扣除背景只用于定义图形的有效对比度，除法只用于统一数值尺度；两者都不修改前向输出或显示结果。

### 6.2 固定三档比例

令公共最高档尺度为 `Q`，目标响应为：

```text
[Q/3, 2Q/3, Q]
```

首轮不自由学习三个比例。`Q` 可由当轮所有通道最高档响应的公共统计量确定，但应停止梯度穿过该统计量，避免通过移动目标本身获取虚假低损失。原图像损失和目标区效率项必须保留，以防所有档位共同塌缩到低亮度。

### 6.3 损失组成

- `L_image`：保留现有图案/效率损失，负责形状和有效能量。
- `L_level`：所有 `(channel, level)` 接近公共 `Q/3、2Q/3、Q`。
- `L_cross`：逐灰度档缩小 `S[c,l]` 的跨通道 CV，约束同档有效亮度一致。
- `L_gap`：保证每个通道三档严格单调并具有最小间隔。
- `L_line_uniform`：降低同一条线内部的强度方差，避免斑驳。
- `L_visibility`：只保证最低灰度线高于本通道背景，避免图形被背景完全淹没。
- `L_worst`：约束最差的 `(channel, level)`，防止平均指标掩盖失败通道。

根据用户对阶段 C 统一曝光结果的复核，阶段 D 已确认加入背景均匀性约束：不强制各通道背景均值一致，也不把背景能量压到零。最终约束应对所有背景像素统一作用，使用归一化背景亮度带和方向无关的局部背景亮度集中惩罚；背景像素方差和逐行均值方差只作为辅助指标，不能把某种横向纹理作为专用优化目标。

## 7. 阶段 E：权重探索

采用由短到长的分级实验，避免直接进行大量长跑：

1. 小轮数检查梯度、数值稳定性、单调性和输出完整性。
2. 只扫描少量具有解释性的组合：先分别打开 `L_level/L_cross`、`L_gap`、线条均匀性、可见性项和背景逐行均匀性，再组合。
3. 淘汰出现档位塌缩、背景淹没线条、最差通道失效或只在逐通道归一化图上好看的组合。
4. 对少数候选使用相同随机种子执行中等轮数。
5. 选定一个候选后再执行正式轮数，并至少增加一个随机种子复核。

不要引入自动重试、动态兜底或复杂权重调度。若固定权重无法工作，应先报告各损失冲突，再决定是否尝试自适应灰度比例。

## 8. 输出与验收

每次实验至少保存：

- 最终 `dx/dy`、原始 `I_c` 和统一曝光图。
- `23 × 3` 非零灰度响应矩阵。
- 每档跨通道均值、CV、最大偏差和最差通道。
- 每通道三档比例误差、单调性和最小间隔。
- 每条线内部方差。
- 每通道背景均值、背景方差、背景逐行方差和背景高分位峰值；背景亮度带越界损失对所有背景像素统一作用，背景方差与逐行方差保留为辅助指标，不再把某种横向纹理作为最终目标。
- 原损失与所有新增分项损失的历史。
- 同一显示范围下的 23 通道结果总览，禁止用逐通道最大值归一化作为灰度证据。

首要人工验收是所有通道中三条线肉眼明显分开。数值指标用于定位失败通道和比较权重，不在探索前伪造一个未经验证的硬门槛。

## 9. 阶段 F：用户复核点

三线正式结果生成后暂停，由用户查看统一曝光图和最差通道。未经用户确认，不进入水果图实验。

## 10. 阶段 G：水果轮廓

用户已明确要求跳过第二种子复核并直接进入水果迁移。输入中的 23 张图是二值水果线稿；应先逐通道填充封闭轮廓，再按到边界的距离生成外层 `1/3`、中层 `2/3`、核心 `1` 三档，必须保持 23 个通道各自的水果图案，不得把所有通道替换成相同水果。先生成目标预览，再训练并检查迁移是否脱离三线局部解。

阶段 G 已完成填充三灰度目标生成和通道缩减对照。失败根因是最大值归一化图案损失受背景亮斑控制，且从随机相位同时启用多项线条校准辅助损失会压过图案主损失，使动态 `Q` 在低亮度下假收敛。

主流程现默认使用总能量归一化灰度分布损失。23 通道 1000 轮验证已恢复所有水果轮廓且 23/23 通道三档单调。后续以该结果热启动，先单独增加跨通道一致性约束；确认轮廓和能量不退化后，再逐项加入背景约束。不要从随机相位直接恢复原有完整辅助损失组合。

轮廓线热启动候选使用 `output/verify_fruit_three_level_lines_ch23_1000/optimized_results.npz` 作为初值，并固定 `reference-q=5.834266`。首个候选只打开低权重 `level` 和 `cross-level` 项，保持线内均匀性、背景和局部集中项为零。比较时至少报告三个档位各自的跨通道 CV、最高档最小/最大响应、23 通道单调数、前景效率以及统一曝光图；如果一致性改善但轮廓或最弱通道退化，则停止增加权重并重新评估公共 `Q`，不自动切换复杂调度。

首个候选已完成：跨通道 CV 从约 `0.53` 降到 `0.31–0.33`，轮廓、单调性和效率均未退化，但最高档仍有 `4.63–13.27` 的范围。下一候选若继续，应从该结果热启动并小幅提高 `level/cross-level` 权重；仍保持其他辅助项关闭，每次只改变一致性权重，避免无法归因。

用户已确认进入只修改损失函数的四目标联合优化。首个联合候选从 `output/verify_channel_consistency_1000/optimized_results.npz` 热启动，固定 `Q=5.834266`，同时使用逐像素结构完整、灰度公共档位、同档跨通道一致性、低权重线内均匀和背景局部热点项。每个候选约1000轮，完成后必须按 `doc/evaluation-metrics.md` 的四类指标与上一候选比较；只有结构、灰度、同档一致性和背景的综合结果更好时才保留。

四目标阶段已完成三个1000轮递进候选。第三候选新增高权重但独立归一化的通道内灰度比例项，解决第二候选灰度比例偏向 `0.390:0.707:1` 的问题；最终恢复为约 `0.347:0.675:1`，同时保持结构覆盖、跨通道一致性和像素背景指标继续改善。当前停止继续叠加权重，保留 `output/joint_loss_candidate_3_1000` 作为综合最优，避免为单独压低背景逐行CV而扩大搜索范围。

用户调整优先级后，追加一个CV优先候选：从第三候选热启动，将固定 `Q` 更新为 `9.198383`，使用 `level=1.0`、`cross-level=5.0`、`gray-ratio=5.0`，背景权重降到 `0.005`。结果将三档CV压到 `0.026/0.043/0.050`，且结构、灰度分级和背景均未明显退化。当前推荐使用 `output/cv_priority_candidate_1000`，不再继续扩大权重搜索。

## 11. 暂不采用的复杂方案

- 自适应学习三个灰度比例：固定比例失败后才作为独立实验。
- 动态损失权重、课程学习或多阶段优化器：会扩大改动和解释难度，当前不采用。
- 重构前向为新模块：虽便于测试，但会触碰用户要求冻结的核心流程，当前仅增加外部回归测试。
- 独立通道增益、逐通道曝光校正、后处理灰度映射：违反物理约束，禁止采用。

## 阶段 H：36级次第一象限扩展

当前按用户确认将物理级次扩展为 `m,n∈{1,…,6}` 的36项笛卡尔积，权重统一为1，36张6×6细线目标全部参与优化。固定前向公式和共享 `dx/dy` 不变。首个1000轮基线用于验证结构可行性，不提前加入一致性损失；结果显示多数通道可形成轮廓，但同方向整数倍级次存在明显耦合，三档CV约0.57。下一步若继续，只允许从该结构结果热启动调整损失；不得通过逐通道亮度缩放补偿。

最新几何线稿先以 `spatial` 方式生成连续三灰度段，避免细线抗锯齿导致的“看起来全白”。目标仍铺满每个500×500通道，不增加边缘保护区。1000轮结构基线之后执行4段各500轮的CV优先热启动，三档CV由 `0.726/0.732/0.735` 降至 `0.054/0.133/0.180`，但结构相似度均值由 `0.492` 降至 `0.358`，覆盖率由 `0.352` 降至 `0.162`。当前停止继续加大CV权重，原因是中高灰度一致性尚未达到0.05，而结构已经明显退化。

下一决策点不是继续盲目增加轮数，而是在两条路径中选择：接受当前36级次折中并回调结构权重，或改变含整数倍谐波的级次集合。第二条会改变物理通道配置，超出“只调损失”的当前范围，未获得确认前不实施。

用户要求提高三级绝对亮度后，已选择第一条路径中的公共亮度热启动：固定 `Q=2`，不改变目标和物理级次，先执行500轮温和校准，再执行两段各500轮强化增亮。最终三档亮度提高约20%–25%，结构与覆盖率同时改善，三档CV保持在 `0.052/0.116/0.150`。当前结果作为增亮候选保留；若继续提升，应每500轮复核一次统一曝光图和四项指标，不直接把 `Q` 再提高到更大数值。

用户随后取消绝对亮度优化，最终方案改为动态公共尺度、关闭绝对档位和最低亮度项，只优化同档CV、灰度比例/间隔、结构与覆盖。两段各500轮后CV降到 `0.009/0.049/0.078`，两个平均相邻差值保持 `0.460/0.485`，36/36通道单调；结构均值约下降5%，覆盖率均值约下降11%，未发生严重结构失效。最终输出统一采用公共 `2×` 入射光强，不进行逐channel缩放。
