# 项目架构说明

## 1. 项目定位

该项目是脚本式科研计算流程，不是 Web 服务或安装包。核心任务是在不可修改的衍射物理前向下，优化两个共享二维相位变量 `dx`、`dy`，使最多36组衍射级次分别形成对应目标图案，并评估各通道的效率、对比度和亮度一致性。当前默认级次为第一象限 `(1,1)…(6,6)`。

## 2. 模块划分

| 分类 | 文件 | 职责 |
|---|---|---|
| 核心优化 | `coding/python/order_decoupling_grayscale.py` | 读取目标、执行固定前向、计算损失、Adam 优化、重建并保存结果 |
| 目标生成 | `coding/python/create_three_level_fruit_target.py` | 保留 23 个独立水果轮廓，逐通道填充封闭区域，并按距离边界的远近生成外层、中层、核心三档目标 |
| 细线目标生成 | `coding/python/create_thin_letter_target.py` | 将输入图满幅切为6×6，并按源亮度或空间连续方式生成三灰度目标，不添加保护区 |
| 权重工具 | `coding/python/calculate_weight.py` | 根据给定通道强度计算补偿后的自定义权重 |
| 结果工具 | `coding/python/show_save_img.py` | 读取既有 `optimized_results.npz`，输出目标图、重建图、曲线和逐通道 CSV |
| 光强测试 | `coding/python/simulate_global_illumination.py` | 对所有channel应用同一个入射光强倍率，验证绝对亮度缩放及CV、灰度比例不变性 |
| 版图工具 | `coding/matlab/mask_generate.m` | 将 `phdx/phdy` 相位 CSV 映射为单元位移并生成 CIF 掩模 |
| 输入 | `input/` | 只保存用户提供的原图和原始 MAT，不保存训练或预览产物 |
| 文档 | `doc/` | 原始任务说明、算法说明、固定前向与损失设计资料 |
| 教学 | `teach/` | CV优先损失方案的任务说明、简洁课程、速查页和学习记录 |
| 输出 | `output/` | 只保存可重新生成的目标 MAT、训练 NPZ、CSV 和 PNG，可整体清理而不影响输入 |

## 3. 主流程

1. `load_targets` 从 MAT 文件读取并校验 `bw_all`；主流程可用 `channel-count` 截取前 N 个通道做可行性隔离。
2. `select_device` 选择 CPU 或 CUDA。
3. 随机初始化两个 `500 × 500` 的共享相位变量 `phdx/phdy`。
4. `total_cost` 对最多36个 `(m,n)` 级次逐一执行固定物理前向：
   - `Φc = mc·dx + nc·dy`
   - `Uc = exp(iΦc)`
   - `Ic = |fftshift(FFT2(Uc))|²`
5. 默认基础损失将目标灰度和重建强度分别按全平面总量归一化，再最小化目标前景分布相对重建分布的 KL 散度；它同时推动能量进入目标区域并保持每像素 `1:2:3` 灰度比例，避免最大值归一化被随机亮斑支配。可选逐目标像素最低响应项用于减少暗点和缺线；线内均匀性按该灰度线自身均值归一化，避免稀疏目标相对全平面均值归一化时数值失控。固定公共 `Q` 的档位损失负责绝对亮度与跨通道一致性，背景方差和局部热点项负责背景均匀。物理前向不参与这些修改。
6. Adam 更新共享的 `phdx/phdy`。
7. `reconstruct` 生成原始强度、逐通道归一化强度和全局统一尺度强度。
8. `channel_metrics` 统计能量效率、前景/背景均值和对比度。
9. 保存数值结果与对比图。

## 4. 数据与输出

主脚本的 `optimized_results.npz` 包含：

- 优化变量：`phdx`、`phdy`
- 训练记录：`costs`、`eta_history`、亮区一致性相关历史
- 固定配置：`pairMat`、`weights`、损失权重
- 输入与重建：`targets`、`optimized_raw`、`optimized_01`、`optimized_global_01`

同一实验目录还会产生：

- `channel_brightness_metrics.csv`
- `grayscale_level_metrics.csv`：三档有效响应、比例、单调性、线内方差、背景方差和背景逐行方差
- `evaluation_channel_metrics.csv`：每个通道的结构、灰度分级和背景均匀性评价
- `evaluation_summary.csv`：当前参与优化通道的四类评价汇总
- `target_vs_optimized_0_1.png`
- `target_vs_optimized_global_scale.png`

## 5. 设计约束

- 物理前向不能改变；改进范围限于目标、损失、损失权重、优化策略和验收指标。
- `dx/dy` 是全部通道共享设计变量，不能通过逐通道后处理缩放冒充器件自身的亮度一致性。

## 36级次配置

当前 `PAIR_MAT` 使用 `m,n∈{1,…,6}` 的笛卡尔积，共36项；所有基础权重统一为1。该配置排除了零轴和正负共轭，但仍存在整数倍谐波耦合，例如 `(1,1)、(2,2)…(6,6)` 的相位均来自同一线性组合的整数倍。1000轮基线表明配置可运行，但最差结构和跨通道CV明显弱于原23级次方案，因此不能把“坐标不重复”等同于“物理通道独立”。
- 跨通道亮度验收应使用原始强度或统一尺度结果，逐通道归一化结果只适合观察图案形状。
- 阶段 D 可使用阶段 C 的 `optimized_results.npz` 作为 `--initial-results`，并通过固定 `--reference-q` 防止公共灰度尺度自缩小。
- 当前程序结构是单脚本主流程，规模较小，暂不需要引入包化、框架化或额外抽象。

## 6. 当前断点

当前36通道几何细线候选的深灰CV已降到 `0.054`，中灰/亮灰CV为 `0.133/0.180`；结构相似度均值为 `0.358`，说明继续压CV已明显损害结构。当前断点是评估是否接受该一致性—结构折中，或另行改变36个物理级次集合；后者属于比调损失更大的方案，尚未采用。Python 主流程输出 `phdx/phdy` 到 NPZ，而 MATLAB 版图脚本读取 CSV，两者之间仍缺少正式导出步骤。辅助脚本还含固定的本机路径。

输入/输出边界已经固定：`input/` 为不可随实验清理的原始数据，`output/` 为可删除的派生产物。2026-08-31 的清理删除了旧输出，因此文档中的旧路径只表示历史实验记录。
