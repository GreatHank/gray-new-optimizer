# 灰度重建结果展示

老虎、星空、乌龟、山涧各保留严格 3×3 与 4×4 的全平面、固定可观测区结果；牡丹、盘龙、凤凰各有严格 3×3 圆内约束结果。均为 500×500 阵列、统一曝光 1×。全平面与圆内 SNR 的统计区域不同，不能直接比较；同掩膜对照见 [实验结果](experiments.md)。
