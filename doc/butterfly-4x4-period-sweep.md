# 蝴蝶图4×4有效周期扫描

## 结论

增大有效衍射周期会显著改善级次传播，但会缩小级次间距和圆形远场FoV。若允许把决定衍射级次间距的物理周期从850 nm改到论文量级，当前推荐：

```text
lambda = 480 nm
P_x = P_y = 2000 nm
m = 1…4
n = 1…4
图块映射 = rot180
theta_i = 58.05194°
phi_i = -135°
传播中心 = 16/16
圆形FoV = 57.37080°
```

这里的 `P` 必须是光栅方程中的有效衍射周期。若850 nm是不可更改的真实有效周期，则2000 nm结果仍只能作为理论对照，不能通过软件选阶实现。

## 2000 nm为什么更合适

原先的 `m=-2…1、n=1…4` 在2000 nm下也能16/16传播，但仍含4个 `m=0` 轴向级次。周期放宽后可以改用完全无轴的第一象限方阵 `m,n=1…4`：

- `(0,0)`：0个；
- `m=0`或`n=0`：0个；
- 正负共轭对：0对；
- 可传播/可收集中心：16/16；
- 最小空气锥余量：0.49088；
- 16个局部角谱方格均完整位于空气圆内；
- 出射中心极角范围：9.7707°–30.6050°；
- 同方向倍数对：8对，非本原谐波级次5个。

最复杂4个源图块在 `rot180` 映射下为：

|复杂度排名|源图块|级次|倍数组|
|---:|---:|---:|---:|
|1|(3,3)|(2,2)|4成员对角组 `(1,1)…(4,4)`|
|2|(2,3)|(3,2)|无倍数伙伴|
|3|(3,2)|(2,3)|无倍数伙伴|
|4|(2,2)|(3,3)|4成员对角组 `(1,1)…(4,4)`|

因此前4复杂块有2块完全无倍频，另外2块落在4成员对角组；没有复杂块落入轴向组。这比850 nm方案中两个中央复杂块落入4成员轴向组更合理，但并未消除所有整数倍耦合。

## 周期—入射角—FoV交换

下表采用共同入射，并在入射方向余弦允许时将4×4角谱方阵严格居中。`完整方格`不只检查16个级次中心，也检查每个级次承载的局部角谱方格四角。

|P (nm)|级次范围|theta_i|phi_i|传播中心|完整方格|圆形FoV|
|---:|---|---:|---:|---:|---:|---:|
|1300|-2…1, 1…4|70.281°|-78.690°|16/16|否|95.201°|
|1358|-2…1, 1…4|64.310°|-78.690°|16/16|是，几乎零余量|89.970°|
|1400|-2…1, 1…4|60.941°|-78.690°|16/16|是|86.584°|
|1800|1…4, 1…4|70.529°|-135°|16/16|是|64.462°|
|2000|1…4, 1…4|58.052°|-135°|16/16|是|57.371°|

关键阈值（lambda=480 nm）：

- 跨轴方阵 `m=-2…1、n=1…4` 严格居中并16/16传播：`P≥1223.76 nm`；
- 该居中4×4的完整局部角谱方格进入空气圆：`P≥1357.65 nm`；
- 无轴方阵 `m,n=1…4` 在掠入射下16/16中心传播：`P≥1357.65 nm`；
- 无轴方阵可严格居中：`P≥1697.06 nm`。

所以有两个不同取向：

1. 若优先较大FoV，可取约1400 nm并保留跨轴方阵，得到约86.58°，但仍有轴向耦合。
2. 若优先16通道完整传播、较温和入射角和避开全部轴向级次，取2000 nm与 `m,n=1…4` 更稳妥；代价是FoV降至约57.37°。

1800 nm是中间折中，但 `theta_i≈70.53°` 仍较斜，传播余量和装调容差不如2000 nm。
