# 研究要求与评价边界

## 当前有效前向与优化

- 全部级次共享逐像素相位图 dx、dy、PP，单位 rad。固定 Φ_c=m_c dx+n_c dy+PP，U_c=exp(iΦ_c)，I_c=|fftshift(FFT2(U_c))|²。
- FFT 沿最后两个轴，采用默认未归一化变换；不改变轴序、级次顺序、模平方与原始尺度。前向改动必须经过独立 NumPy 与 Parseval 回归。
- PP 按 2π 周期回绕至 [-π,π)，不是硬截断；空间变化 PP 允许 00 与正负级次作为目标，多个级次仍受共享仿射相位关系限制。
- 基础损失是 I/(HW) 与 T/mean(T_all) 的共同尺度 RMSE，通道权重固定为 1。`spatial_constraint=full_plane` 使用全部像素；`observable` 使用由几何和 NA 预先固定的各级次可观测像素，按全部有效像素统一求均值。亮度优化可加同灰度跨级次原始均值一致项，gray_consistency_weight 默认 0；不改变目标、前向、raw 或共同显示白值。
- 一致项按原有非黑灰度标签取固定像素；`observable` 模式再与固定掩膜取交集。以像素数加权比较不同级次的同档 I/(HW) 均值；不强迫不同目标灰度相同，不对各通道拟合或应用增益。
- 每轮同时计算全部级次，梯度汇总到同三张相位；目标、级次、波长、周期与共同入射角不在循环中更新。
- Adam 每轮一次前向、反向、更新；L-BFGS 线搜索可能多次求值，比较预算须记录求值次数。
- 热启动只恢复相位并重新建立优化器，不称为恢复完整训练状态。历史记录更新前状态，最终相位与 raw 使用最后更新后的重算状态。
- 几何参数影响出射方向、传播与 NA；当前图块 FFT 没有角度相关器件响应，调角度不能单独作为画质改善原因。

具体公式见 [损失说明](optimizer_vault/03_损失函数与评价指标.md)，流程见 [逐轮优化](optimizer_vault/02_一轮优化与梯度更新.md)。

## 目标与级次

- 当前比较两组用户截图参数：3×3 为 P=800 nm、θ=70.1276°、m,n=-2…0；4×4 为 P=1050 nm、θ=20.9938°、m,n=-2…1。共同 λ=532 nm、φ=45°、NA=1，保留完整 8-bit 灰度。
- 当前实验使用 500×500 共享相位阵列，共 750000 个相位参数，各级次都使用整个阵列。
- 级次严格按用户指定网格执行：3×3 为 9 个，不自动加入外围级次。网格由 target.grid_size、order_m_start、order_n_start 指定，excluded_canvas_positions 可排除无非黑目标的单元。4×4 为 16 个，四角保留。
- 后续精修仅使用严格3×3九级次；4×4不再续跑精修。
- resized_size/canvas_offset 只能整体缩放、放置完整源图，不裁掉内容。几何约束失败时直接报错，不清除圆外像素以伪造通过。
- 用户明确要求源图圆与视场圆重合时，target.source_circle 指定源圆心、半径和圆外背景灰度上限，将源圆整体映射至 min(1,NA/n_out) 的物理视场圆。只有声明范围内的圆外背景可清除；圆内明暗不配平，按准确 FFT 坐标全局双线性采样，原始 input 不变。此模式重新定义 target，不能把其分数与完整原图目标直接当作同一目标的改进。
- 圆形目标的完整覆盖由 target.require_full_field_coverage 指定，默认 true。P800 九宫格宽度 1.995 小于圆直径 2；P1050 的 16 个级次可覆盖完整圆。用户指定严格九级次时设为 false，保留源圆映射及中央九张原有 target，只优化选中的九级次。未选方向不约束，不能显示为优化得到的黑色；记录实际圆面积覆盖率约 99.9700%，不再声称完整圆周覆盖。圆外 target 文件仍为黑；在 `observable` 优化中，圆外数值强度不受图像损失约束。
- 当前输入为老虎、圆形星空、乌龟、山涧、牡丹、盘龙和凤凰，各图使用独立目标与配置。默认入口为乌龟严格九级次；老虎整图保留比例与内容，圆形图按各自源圆参数映射。
- 行优先顺序固定，m 向右增加、n 向上增加；MAT 的 order_pairs、grid_positions、canvas_positions 语义分开，结果保存实际级次和位置。
- 四灰度包括背景 0 和 1/3、2/3、1；当前 gray_level_count=256。目标标签无损保存。
- 禁止为提高分数逐通道改增益、单独调方向、配平目标、改统计窗口或隐藏越界区域。

## 指标与展示

必须区分：

- 原始亮度：raw 在固定评价区域内的原有非黑标签像素均值。
- 有效响应：S_(c,ℓ)=(μ_(c,ℓ)-μ_bg,c)/mean(raw_c 在同一评价区域)。
- 灰度比例：最高档存在时 S_(c,ℓ)/S_(c,K-1)，缺档保留 NaN/null。
- 显示灰度：全通道共同白值 HW/mean(T_all)，倍率统一且标注。
- SNR=20log10(μ_fg/σ_bg)，CNR=(μ_fg-μ_bg)/σ_bg。
- 可观测区能量占比：固定掩膜内 raw 总和/完整 FFT raw 总和，只是软件频谱分布指标，不是器件效率。

`full_plane` 旧结果的主指标使用完整平面，前景 T>0、背景 T=0。`observable` 新实验的 RMSE、SNR、CNR、灰度响应只使用按实际角度坐标、传播条件及 NA 固定的掩膜；背景为掩膜内原图黑色像素，缺少有效背景时 SNR/CNR 无定义。两种空间范围的原始分数不可直接比较，须用同一掩膜和共同尺度重评。完整 FFT 始终计算、保存，并另报总强度及可观测区能量占比；圆外频谱不解释为真实可传播功率的储存区。曝光只改 PNG，不改 raw、损失或评价。

已选中的纯背景级次保留在优化、能量、背景和全平面误差中；其前景均值、结构相似度、SNR/CNR 无定义，保存为 NaN/null。未选级次不自动补入。前景指标均值仅汇总有前景级次并记录数量，不更换任何像素窗口。

逐轮 SNR、CV、能量占比是无梯度观测；最终灰度单调性与比例误差也不参与当前损失。同灰度原始均值一致项由显式权重决定是否参与。单个指标改善不等于整体画质通过。

[Paper] 论文 SI S5 式 S9 的 SNR 与上述形式一致，15 dB 是平均 SNR 阈值。

[Question] 项目用目标标签定义信号/背景区域，论文精确掩膜待核对；不能只凭相同公式直接对标数值。

## 物理与器件边界

- 全部级次使用同一次共同照明，波长、周期、折射率、NA 和角度明确记录。
- 严格几何门槛由每个实验配置指定。当前两组均要求所有方格与传播圆相交、所有实际非黑目标入圆。3×3 中心传播数 9/9，4×4 为 12/16；中心可在圆外，但方格有可传播部分。通过不等于所有方格完整传播。
- 完整方形 FFT 与传播圆内图像分别命名；圆外频谱不计为可传播光场，`observable` 模式不对它施加图像损失。
- PP 是附加标量相位，不是已验证 PB 旋转自由度；软件自由度不等于可制造纳米砖。
- 软件 FFT、几何支撑、单元响应、联合分光、全波与实验是不同验证层。缺少证据明确未验证。
- 当前工作代码不含制造导出，不自动生成相位 CSV/CIF 或启动 FDTD。

论文事实与项目推断见 [physics.md](physics.md)。

## 文件与维护

- 原始输入 input；派生目标 output/targets；优化相位、指标、完整报告和跨实验比较放 output/data。
- output/runs 只用于看图：按原始图片分类，老虎、星空、乌龟、山涧各有严格 3×3 与 4×4 的全平面、圆内约束版；牡丹、盘龙、凤凰各有一张严格 3×3 圆内约束版。每次优化只生成一张左 target、右效果图。文件名包含级次方案、阵列尺寸、步数（续跑同时标累计与本轮步数）、周期、目标模式、优化器、seed 和北京时间；图中标平均 SNR，统一曝光 1×。灰色区域明确表示未选或不可传播区域。
- 实际原始文件由 configs/selected-results.json 的 data_dir 定位；热启动使用 output/data，不从 PNG 恢复。
- 只维护共享 dx/dy/PP 流程；结果读取和热启动必须包含 PP，目标由无损标签及明确灰度数恢复。
- 代码按功能放 coding/targets、optimization、geometry、results，测试放 coding/tests；当前流程统一 Python。
- 参数试验用配置与独立 run id，不复制算法或为调参建分支；main 为长期主线。
- 文档描述当前可用功能。output 保留 P800 与 P1050 的目标、运行、报告和比较，当前阵列均为 500×500，级次方案为严格九级次或十六级次。现有目录不覆盖；重跑使用新的 run id。

## 两种网格的比较

两组均从相同 seed=43 的三张 500×500 参数图随机初始化，Adam 25000 步、lr=0.001、同灰度一致权重 1，不使用其他结果热启动。相同更新次数不是相同计算成本；4×4 每步需计算 16 个 FFT，3×3 为 9 个。比较图使用同一角度坐标和共同 raw 白值，单组主指标继续使用各自原有完整目标与统计窗口。SNR 为逐级次 dB 的算术均值，同时报告最低值；目标切分与采样不同，仅评价本次两组配置，不能据一次实验概括算法优劣。
