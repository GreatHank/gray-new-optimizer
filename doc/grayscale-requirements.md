# 四级灰度需求

状态：在历史23通道实验基础上，用户已确认扩展为第一象限 `(1,1)…(6,6)` 的36级次方案，并完成首个1000轮结构基线。

## 目标

在完全冻结现有物理前向的条件下，仅通过损失函数引导共享 `dx/dy`，把原来的二值线图扩展为四级显示：黑色背景以及 `1/3`、`2/3`、`1` 三档可见线条。

第一阶段使用简单细线校准图，优先验证三档线条是否肉眼明显分开，以及不同衍射通道是否能保持一致的灰度关系。成功后再迁移到现有 23 张水果轮廓线图。

## 不可变边界

- 物理前向 `Φc = mc·dx + nc·dy → exp(iΦc) → FFT2 → |·|²` 不得改变。
- 最多36个通道继续共享同一组 `dx/dy`。
- 不允许在 FFT 后乘逐通道增益、改变传播逻辑或通过显示范围伪造灰度效果。
- 优化流程的物理逻辑不得改变；允许扩展目标读取、指标统计和结果输出。
- 算法层面的改进集中在损失函数及其权重。

## 已确认需求

- 四级包含黑色背景，不是“黑背景外再加四档”。
- 三个非零档的首轮目标比例可使用 `1/3 : 2/3 : 1`。
- 后续允许对公共灰度比例进行受约束的自适应探索，但应先完成固定比例基线。
- 同一非零灰度档在不同通道中的“高于各自背景的有效线条亮度”应一致。
- 一致性先扣除该通道背景平均值，再除以全平面平均强度。固定前向下各通道全平面平均强度相同；该计算只用于损失和验收，不改变输出强度。
- 黑背景平均亮度允许因通道而异。
- 允许剩余能量分散在黑背景中，但背景应尽量空间一致，不能形成明显亮斑、横线鬼影或破坏线条辨识度。
- 优先级一：三档线条肉眼明显分开。
- 优先级二：不同通道保持一致的灰度关系。
- 第一阶段使用细线而非大色块；第二阶段使用不同通道的水果轮廓图。

## 灰度响应定义

设第 `c` 个通道、第 `l` 个非零灰度档的线条平均原始强度为 `mu[c,l]`，背景平均值为 `bg[c]`，全平面平均强度为 `plane_mean[c]`：

```text
S[c,l] = (mu[c,l] - bg[c]) / plane_mean[c]
```

三个非零档共享公共有效响应 `Q/3、2Q/3、Q`，其中 `Q` 是所有通道共同的最高档有效亮度尺度。每一档既要在通道内保持比例，也要在不同通道之间接近同一公共值。

这是基于视觉对比和能量可行性的明确取舍：允许不同通道的背景基线不同，只要求背景之上的三档有效信号一致。它不属于 FFT 后增益，因为训练和输出的 `I_c` 均保持原样。

背景不是跨通道均值优化对象：不要求各通道背景均值相同，也不把背景能量强行压到零。阶段 D 先验证弱背景像素方差和背景逐行均值方差，再增加对所有背景像素统一作用的亮度带损失；后者用于压制集中亮斑和亮块，不针对某一种横向纹理。背景均值、方差、逐行方差和高分位峰值仍作为观察指标输出。

## 校准图约定

- 图像尺寸保持 `500 × 500`。
- 所有 23 个通道先使用相同的三线校准图，以单独观察衍射级次差异。
- 使用三条等长、等粗、彼此分离的水平细线。
- 从上到下标签依次为 `1/3、2/3、1`，其余像素为背景。
- 首轮固定比例；自适应比例只作为固定比例效果不足时的独立对照实验。

## 当前决策记录

### D-001：先校准、后水果

先使用结构简单且每档像素数明确的三线校准图，排除复杂轮廓、面积差异和空间位置对灰度可行性判断的干扰。校准成功后，再验证不同通道的水果轮廓。

### D-002：背景作为允许的能量出口

各通道总能量受固定前向约束。背景无需跨通道同亮度，可承接未进入三档线条的剩余能量。背景允许存在一定杂散，只要三档线条结构和灰度仍可辨认。

### D-003：同档线条采用公共背景增量

相同灰度档以“线条均值减去本通道背景均值”后的有效亮度进行跨通道比较。该方案比强制原始绝对线条均值相等更容易满足固定总能量约束，也更符合图形的视觉对比。背景差异被明确允许并单独报告。

### D-004：背景横线鬼影列为阶段 D 优先问题

用户复核阶段 C 统一曝光图后确认，背景中与目标线相似的横向条纹不可接受。阶段 D 在保留图像结构损失的前提下，加入弱背景像素方差和背景逐行均值方差损失；该约束不改变物理前向，也不要求背景跨通道同亮度。

### D-005：改用全背景亮度带抑制集中亮斑

用户进一步确认，不接受针对特定横向纹理的专用约束，希望所有背景亮点都受到抑制并尽量分散。阶段 D 增加全背景像素亮度带损失：在排除目标线的背景掩膜内，对归一化原始强度 `I / 全平面均值` 统一施加上下限越界惩罚。只设置上限时重点抑制亮斑；设置上下限时同时推动背景亮度落入指定区间。两组 2000 轮热启动短实验均保持三档结构，但尚未消除可见残余扩散纹，不能宣称通过验收。

### D-006：增加方向无关的局部集中惩罚

为直接抑制背景亮斑集中成块，阶段 D 增加局部背景平均亮度惩罚。对每个背景像素计算指定邻域内的背景平均亮度，超过局部上限时产生惩罚；卷积邻域不区分横向、竖向或其他方向。9×9 和 21×21 两组短实验均保持三档结构，9×9 的背景方差较低，但统一曝光图仍有可见残余扩散纹。

在 9×9 方案上提高局部集中惩罚权重至 `2.0` 并收紧局部上限至 `0.9` 后，背景方差进一步下降到约 `0.5064`，但残余扩散纹仍未根除，因此继续保留“背景无可见结构纹”的硬验收条件。

### G-001：水果三灰度目标规则

用户要求直接进入水果迁移。原始 `input/grayscale_image.mat` 包含 23 个二值水果线稿，而非三灰度实体。当前目标生成先逐通道填充封闭轮廓，再根据像素到边界的距离生成外层 `1/3`、中层 `2/3`、核心 `1`，黑色区域保持为 0。填充后的总前景占比约为 `1.98%`。

### G-002：第一次水果迁移失败

使用阶段 E 三线结果热启动进行 5000 轮水果迁移后，优化结果仍主要保留水平线：目标水果区域平均获得约 `0.93%` 能量，目标外能量约 `99.07%`，三档响应平均接近零。该结果说明热启动路径陷入三线局部解，不能作为水果迁移成功结果。

随后使用水果专用随机初始化，并关闭所有背景损失进行 1200 轮结构快速检查；目标水果区域平均获得约 `0.96%` 能量，目标外能量约 `99.04%`，23 个通道均未保持三档单调，仍未出现水果雏形。该结果排除了“仅由背景约束导致目标消失”的解释，当前不再盲目增加轮数。

### G-003：稀疏目标损失结构修复与复验

水果前景只占约 `0.96%` 平面像素。为避免总 MSE 被背景像素数量主导，主流程新增前景/背景分区平均图案损失；同时新增独立的前景能量集中项。复查发现第一次命令行 balanced 试跑中，主循环未将三个新参数传入 `total_cost`，导致实际仍使用旧 `sum` 损失，该问题已修复并通过 8 项回归测试。

修复后的 1000 轮 balanced 试跑 `output/stage_g_fruit_1000_balanced_seed123_nobg_v2`，以及加入前景能量集中项的 1000 轮试跑 `output/stage_g_fruit_1000_balanced_efficiency_seed123_v3`，原线稿前景能量仍约 `0.96%`，输出仍为均匀噪声。改用填充三灰度目标后，1000 轮试跑 `output/stage_g_filled_fruit_1000_balanced_efficiency_seed123` 的前景能量约 `1.98%`，仍未出现水果雏形。由此确认当前不显示水果不能归因于轮数不足或原始线稿过稀疏；剩余问题更可能在共享 `dx/dy` 对 23 个不同空间位置水果的可表达性，或当前归一化/灰度约束与该目标的组合上。后续若继续，应先做单通道/少通道可行性隔离，再决定是否调整目标或优化流程。

### G-004：二值路径与通道缩减复验

复查发现主流程对二值目标仍计算空的 `1/3`、`2/3` 灰度集合，造成 NaN；现已改为二值路径跳过灰度档损失，并增加逐通道回归测试。修复后原始二值目标 3 通道 5000 轮 `output/stage_binary_5000_ch3_old01` 能恢复梨、南瓜和五角星轮廓。填充三灰度目标 3 通道 5000 轮 `output/stage_g_filled_fruit_5000_ch3` 仍未稳定恢复，说明旧 0–1 流程成功与当前三灰度流程失败之间确有目标/损失结构差异。

### G-005：改用总能量归一化灰度分布损失

对照发现旧图案损失先除以单个最亮像素，随机背景亮斑会控制整个通道的归一化尺度；动态 `Q` 又跟随当前最高档响应，因此三档可以在整体接近背景时维持 `1:2:3`，形成“指标正确、图像全黑”的假收敛。现默认把目标灰度和重建强度转换为全平面能量分布，并最小化目标前景分布相对重建分布的 KL 散度。该损失不改变物理前向，也不使用通道后处理增益。

23 通道、1000 轮随机初始化验证 `output/verify_three_level_energy_ch23_1000` 中，23/23 通道三档单调，平均比例约为 `0.349:0.684:1`，前景能量占比均值约 `6.25%`，所有水果轮廓可见。该结果只作为短跑路径验证；跨通道绝对响应范围仍较大，后续应从该解热启动并逐项增加一致性或背景约束。

### G-006：轮廓线通道亮度一致性方案

用户指定的水果灰度轮廓线结果 `output/verify_fruit_three_level_lines_ch23_1000` 已恢复轮廓和通道内灰度比例，但三个灰度档的跨通道 CV 均约为 `0.53`，最高档有效响应范围为 `2.52–14.68`。这说明能量分布损失只能保证每个通道内部的目标分布，不能单独保证不同通道的绝对亮度。

下一阶段从该结果热启动，不从随机相位重新开始。固定公共最高档响应 `Q=5.834266`，对所有 `(channel, level)` 使用对称约束，使响应接近 `Q×[1/3,2/3,1]`；同档跨通道离散度作为辅助约束。固定 `Q` 用于阻止所有通道通过共同变暗降低一致性损失。整体前景均值一致性不作为主约束，因为不同水果中三档像素数量不同，会把灰度构成差异误判为通道亮度差异。

低权重热启动候选 `output/verify_channel_consistency_1000` 使用 `level=0.05`、`cross-level=0.02` 完成1000轮。三个档位的跨通道 CV 降至 `0.322、0.327、0.311`，最高档响应范围收窄为 `4.63–13.27`，23/23 通道仍单调，平均前景效率提高到 `5.87%`。该候选证明约束方向有效，但响应范围仍偏大，不能作为最终一致性通过结果。

### H-001：36级次扩展

用户确认使用 `m,n∈{1,…,6}` 的36个第一象限级次，禁止零轴、负级次和FFT后逐通道缩放。基础权重统一为1，36张6×6满幅细线目标全部参与优化。1000轮结构基线可形成多数轮廓，但结构相似度均值/最差为 `0.491/0.155`，三档跨通道CV约为 `0.57`。该结果暴露了整数倍谐波耦合：排除正负共轭并不能消除 `(1,1)/(2,2)` 等共享方向的强相关性。后续若继续优化36级次，必须将这一物理耦合作为限制保留，不能通过逐通道增益掩盖。

### G-007：四目标联合损失

后续改动只允许发生在损失函数和权重，不改变目标、固定物理前向、共享 `dx/dy`、通道增益或显示方式。联合目标同时覆盖结构完整、通道内灰度分级、同灰度跨通道一致性和背景均匀。结构项在能量分布损失之外增加逐目标像素最低响应惩罚；线内均匀性使用每档自身均值归一化的方差。跨通道项继续使用固定公共 `Q`，背景项使用像素方差和方向无关的局部热点约束。候选选择必须依据四项评价，而不是只看总损失。

三个递进候选完成后，`output/joint_loss_candidate_3_1000` 为当前综合最优。它保持23/23通道灰度单调，三档均值比例约 `0.347:0.675:1`，结构覆盖率均值为 `98.2%`，三档跨通道CV约 `0.14`，背景像素CV降到 `0.945`。逐行背景CV为 `0.052`，比联合优化前的 `0.048` 略高，因此背景大尺度均匀性没有同步改善；该限制必须在结果评价中保留，不能宣称所有背景指标都已最优。

### G-008：同灰度CV优先

用户明确将同灰度跨通道一致性设为最高优先级，背景噪声只需保持可接受。以第三联合候选为初值，将固定公共亮度更新为当前最高档均值 `Q=9.198383`，并显著提高同档离散度损失权重。1000轮结果 `output/cv_priority_candidate_1000` 的三档CV为 `0.026/0.043/0.050`，同时结构覆盖率均值为 `98.7%`、23/23通道单调、灰度比例RMSE为 `0.0077`，背景像素CV为 `0.949`。该结果在主要优先级上显著优于此前候选，成为当前推荐结果。

### H-002：36通道几何细线与空间连续灰度

新输入统一保存为 `input/geometric_network_reference.png`。原图线宽很细，若按源像素亮度量化，深灰和中灰主要落在抗锯齿边缘，亮灰落在线芯，缩放预览后会误认为没有灰度。目标生成器新增显式 `spatial` 分档：在每个满幅图块内按像素空间位置把有效线条连续分成三组，再赋值 `1/3、2/3、1`。该操作只生成目标，不修改物理前向，不添加保护区，也不对各channel做亮度缩放。

1000轮结构基线的三档CV约为 `0.726/0.732/0.735`。从该结果热启动并逐步提高已有的固定档位与跨通道一致性损失后，最终候选 `output/geometric_network_36_cv_stage4_500` 的三档CV为 `0.054/0.133/0.180`，36/36通道仍保持单调；代价是结构相似度均值从 `0.492` 降到 `0.358`，前景覆盖率从 `0.352` 降到 `0.162`。因此本目标上只有深灰档接近 `0.05`，不能宣称三档均已达到。继续增加一致性权重会优先压暗强通道并损害细线完整性，当前在该点停止。

### H-003：公共亮度提升

为改善统一曝光下图案偏暗的问题，从H-002候选热启动，将所有通道共用的最高档目标由 `Q=1` 提高为 `Q=2`，同时提高已有的对称档位、单边档位下限、结构完整和前景能量损失权重。没有改变损失公式、物理前向、通道权重或显示尺度，也没有加入逐channel缩放。

先用500轮温和权重校准一致性，再用两段各500轮强化增亮后，三档有效亮度从 `0.399/0.823/1.262` 提升至 `0.479/1.013/1.580`，分别增加约 `20.2%/23.0%/25.2%`。结构相似度均值同步由 `0.358` 提高到 `0.403`，覆盖率由 `0.162` 提高到 `0.223`；36/36通道保持单调，三档CV为 `0.052/0.116/0.150`。该候选说明从背景向线条重新分配能量可以实现真实增亮，但目前仍没有完全达到 `Q×[1/3,2/3,1]`，更强增亮需要继续接受CV、结构和背景之间的折中。

### H-004：统一入射光强缩放

照明强度变化必须使用一个作用于所有36个channel的公共正倍率 `k`，即 `I'_c=kI_c`；禁止使用随channel变化的 `k_c`。`1×/2×/4×` 数值测试确认平面均值和三级原始有效亮度分别变为1、2、4倍，而三档CV固定为 `0.052/0.116/0.150`，三级相对比例固定为 `0.311:0.646:1`。在不考虑探测器饱和、材料非线性和噪声底的当前线性模型中，结构、效率比例和跨通道相对关系也不变。

显示验收必须固定同一个曝光上限；若每个倍率分别归一化到自身最大值，三张图会看起来一样，从而掩盖绝对亮度增加。固定曝光预览和CSV位于 `output/global_illumination_test_1x_2x_4x`。

### H-005：取消绝对增亮、保间隔的CV优先收尾

用户确认不再由优化器追求绝对亮度，只要求三级差值/比例不塌缩，并将跨通道CV作为首要目标；最终照明统一使用全局 `2×`。因此收尾阶段设置动态公共尺度，关闭对称绝对档位和最低绝对亮度项，仅提高跨通道同档一致性、灰度比例、最小间隔、结构完整和前景能量权重。

两段各500轮后，三档CV由 `0.052/0.116/0.150` 降至 `0.009/0.049/0.078`，三级比例RMSE由 `0.0327` 降至 `0.0181`；平均相邻差值保持为 `0.460/0.485`，36/36通道严格单调。结构相似度均值从 `0.403` 降到 `0.383`，覆盖率均值从 `0.223` 降到 `0.198`，但最差覆盖率从 `0.122` 提高到 `0.147`，背景指标基本不变。该结果在显著降低CV的同时保留了可用结构和灰度间隔，成为当前推荐候选。
