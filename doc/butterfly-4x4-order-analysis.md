# 蝴蝶图连续无零级 4×4 级次与空间角分析

## 推荐结果

针对 `input/butterfly.png`，推荐连续级次为：

```text
m = -2…1
n = 1…4
整个4×4图块映射逆时针旋转90°（rot90_ccw）
```

该集合包含16个连续笛卡尔级次，不含 `(0,0)`，正负共轭对为0。在固定结构 `lambda=480 nm、P=850 nm、空气、NA=1` 下，共同入射搜索结果为：

```text
入射横向方向余弦：(u_ix,u_iy) = (0.282500,-0.847000)
theta_i = 63.236°
phi_i   = -71.555°
可传播级次中心 = 10/16
传播中心最小空气锥余量 = 0.10696
```

选择依据是先最大化850 nm下的传播中心数，再对蝴蝶图复杂度加权倍频负担进行排序，并对轴向组施加4倍附加权重。在要求 `(0,0)` 禁止、且2000 nm理论对照能实现16/16传播的候选中，10/16是本次搜索得到的最大值。

## 图像复杂度

图片尺寸为2048×2048。按4×4切分，每块复杂度定义为：

```text
C = 0.5 × 归一化亮线密度 + 0.5 × 归一化边缘总变差
```

最复杂4块集中在中央2×2：`(3,3)、(2,3)、(3,2)、(2,2)`，复杂度分别为`0.9944、0.9932、0.9825、0.9667`。

## 映射关系

`rot90_ccw`后的级次—源图块映射如下。每行的第一个坐标是 `(m,n)`，括号内是原图块 `(行,列)`：

| m\n | 1 | 2 | 3 | 4 |
|---:|---:|---:|---:|---:|
| -2 | (-2,1)←(1,4) | (-2,2)←(2,4) | (-2,3)←(3,4) | (-2,4)←(4,4) |
| -1 | (-1,1)←(1,3) | (-1,2)←(2,3) | (-1,3)←(3,3) | (-1,4)←(4,3) |
| 0 | (0,1)←(1,2) | (0,2)←(2,2) | (0,3)←(3,2) | (0,4)←(4,2) |
| 1 | (1,1)←(1,1) | (1,2)←(2,1) | (1,3)←(3,1) | (1,4)←(4,1) |

最高复杂的4块全部具有可传播中心；局部角谱空气锥交叠比例依次约为`67.1%、100%、67.1%、100%`。

## 倍数耦合

所有级次按 `gcd(|m|,|n|)` 约化后统计完整本原方向组。多成员组只有三组：

| 本原方向 | 成员数 | 成员 |
|---:|---:|---|
| (-1,1) | 2 | (-2,2), (-1,1) |
| (-1,2) | 2 | (-2,4), (-1,2) |
| (0,1) | 4 | (0,1), (0,2), (0,3), (0,4) |

其余8个级次没有同方向倍数伙伴。共线倍数对总数为8，非本原级次5个。

图像复杂度方面：

- 最复杂8块中4块没有倍数伙伴。
- 最复杂4块中只有 `(3,3)→(-1,3)` 完全无倍频。
- `(2,3)→(-1,2)` 位于2成员组。
- `(3,2)→(0,3)` 与 `(2,2)→(0,2)` 位于4成员轴向组。

这说明推荐方案优先保证传播和中央细节进入空气锥，但不能避免中央复杂块落到 `m=0` 轴向组。若强制完全避开高复杂轴向组，次选方案只有8/16中心传播，而且需要约89.16°近掠入射，因此暂不推荐。

## 逐级次空间角数据（480/850 nm）

方向余弦公式为：

```text
u_x = u_ix + m lambda/P
u_y = u_iy + n lambda/P
theta_out = asin(sqrt(u_x²+u_y²))
phi_out = atan2(u_y,u_x)
```

## 视场与角谱覆盖

- 4×4角谱的名义内接圆方向余弦半径：`2lambda/P=1.12941`。
- 空气锥裁切后的名义圆形FoV上限：180°。
- 完全进入空气锥的圆半径比例：约88.54%；外侧约11.46%半径会发生裁切。
- 由于无零级单侧方阵不能完全居中，推荐实际4×4方格总面积中约51.66%位于空气锥内。
- 复杂度加权后约60.89%的图像细节面积位于空气锥内。
- 10个传播中心的出射极角范围为23.526°–63.257°。
- 共有12/16个局部级次方格与空气锥相交，其中10个中心在圆内，2个仅边缘相交。
- 角谱在 `u_y=0` 方向横跨空气锥两侧，横向角域上限为180°；在 `u_x=0` 方向约从-34.37°到90°，纵向跨度约124.37°。这不是完整圆形180°图像覆盖。
