# 固定物理前向的多通道灰度优化：概念迁移包

这个文件夹是从当前项目中提炼出的**可独立迁移概念文档**。它面向一次从零重建：保留已经确认的物理前向，只重新实现数据、损失、优化与验收。

## 最高优先级约束

> **物理前向不能改。只允许通过目标、损失函数、损失权重、优化策略和验收指标，引导共享 `dx/dy` 找到更合适的解。**

固定前向为：

\[
\Phi_c=m_cdx+n_cdy
\]

\[
U_c=\exp(i\Phi_c)
\]

\[
I_c=\left|\operatorname{fftshift}(\operatorname{FFT2}(U_c))\right|^2
\]

`dx/dy` 是允许被优化的设计变量；不可改变的是从 `dx/dy` 到 `I_c` 的物理映射规则。

## 当前证据摘要

在23通道二值目标、相同固定前向和5000轮条件下，只增加亮区一致性与最差通道损失后：

| 指标 | 原损失 | 新损失 |
|---|---:|---:|
| 白线平均原始强度CV | `45.43%` | `2.26%` |
| 最亮/最暗白线均值跨度 | `6.089×` | `1.073×` |
| 最差图案/背景对比度 | `2.78` | `6.89` |
| 平均归一化MSE | `0.007416` | `0.007919` |

它证明了“固定前向、只改损失”可以显著改善一个白色灰度档的跨通道一致性，但尚未证明连续灰度或真实器件绝对级次功率一致。
