# 1. 项目目标与不可变约束

## 1.1 重建目标

从零建立一个多通道相位优化器，使多个衍射级次分别形成目标图案，并最终支持同一套公共灰度响应：

> 无论属于哪个channel，同一个目标灰度档都对应相同的原始光强；不同灰度档之间保持稳定、可调、单调的亮度间隔。

第一阶段应先复现23通道二值目标，再验证白线一致性；第二阶段扩展到4个灰度档。通道数量可一般化为 `K`，但不可同时改变物理前向定义。

## 1.2 最高设计原则：冻结物理前向

以下内容在新项目中必须视为**不可变规格**：

1. 通道相位由 `Φ_c=m_cdx+n_cdy` 形成；
2. 近场为单位模复场 `U_c=exp(iΦ_c)`；
3. 传播使用既定二维FFT与既定 `fftshift`；
4. 强度定义为复振幅模平方；
5. `(m_c,n_c)` 级次表在一次实验中固定；
6. 所有通道共享同一对 `dx/dy`；
7. 不在FFT之后引入逐通道增益、归一化补偿或亮度重映射；
8. 不通过裁切、隐藏能量或改变统计窗口伪造性能提升。

这里的“前向不能动”是新项目的工程约束。若未来物理假设被证明错误，应建立一个独立研究项目，而不是在本重建项目中悄悄修改。

## 1.3 允许调整的范围

允许调整：

- 输入目标的组织方式与灰度档定义；
- 图案损失、亮度一致性损失、最差通道损失；
- 黑背景、杂散、灰度间隔、档内均匀性等损失；
- 各损失权重或增广拉格朗日乘子；
- Adam等优化算法、学习率、轮数和初始化；
- 训练日志、原始数据输出与验收指标。

不允许调整：

- 为某个channel新增独立 `gamma_c` 或 `power_weight_c` 并进入前向；
- 每个channel除以自己的最大值后再声称绝对亮度一致；
- 对输出图逐channel拉亮、拉暗；
- 为了结果好看改变FFT归一化、频谱窗口或能量统计范围；
- 给不同channel使用不同的物理传播公式。

## 1.4 “只改损失”究竟意味着什么

损失函数不会直接改写远场图像。完整链条必须保持：

```text
损失定义什么结果更好
  → 自动微分计算损失对共享dx/dy的梯度
  → 优化器更新dx/dy
  → 冻结的物理前向重新计算所有channel
  → 得到新的原始远场
```

因此性能改善必须来自新的 `dx/dy` 产生了不同干涉分布，而不是后处理伪造。

## 1.5 能力声明边界

重建项目可以声明：

- 固定软件前向内的图案质量；
- 原始强度标尺下的跨通道亮区一致性；
- 四灰度档的响应矩阵、CV、最差误差和单调性；
- 固定前向回放与优化输出的一致性。

在没有全波仿真或实验测量时，不能声明：

- 真实材料和结构的绝对效率；
- 实物各衍射级次绝对功率相同；
- 偏振、耦合、制造误差已满足要求；
- 软件中的逐级次理想FFT等价于真实器件联合分光。
