# 6. 从零重建路线

## 阶段0：建立不可变前向

目标：只实现数据结构和固定物理前向，不写复杂损失。

完成条件：

- `Φ=m·dx+n·dy`、单位模复场、FFT、fftshift和模平方实现完成；
- 固定输入回归数组通过；
- Parseval测试通过；
- 前向配置集中、只读、可序列化；
- 代码评审明确禁止后续损失模块修改前向。

## 阶段1：复现二值基线

目标：用原损失复现23通道二值图案。

完成条件：

- 输入只接受0/1；
- 原形状损失和效率因子实现；
- 结果可由最终 `dx/dy` 独立回放；
- 保存原始强度，不以逐channel归一化图作为亮度证据。

## 阶段2：加入原始亮度验收

目标：先测量，不改变损失。

完成条件：

- 输出白线均值、背景均值、目标区效率和对比度；
- 输出统一曝光图；
- 报告白线CV、跨度、最差通道；
- 明确原基线的亮度不一致程度。

## 阶段3：二值白线一致性

目标：只改损失，验证一个亮度档可以统一。

完成条件：

- 加入 `L_consistent`；
- 加入 `L_worst`；
- 保留 `L_base`；
- 扫描少量权重组合；
- 在固定前向回归测试不变的条件下完成正式轮数；
- 与原基线比较CV、跨度、最差对比度和形状误差。

## 阶段4：四灰度校准图

目标：验证公共四档响应，不直接使用复杂自然图。

校准目标要求：

- 每个channel包含相同面积的4个灰度块；
- 每档像素数量足够；
- 图案位置覆盖不同空间区域；
- 额外保留允许承接剩余能量的区域。

完成条件：

- 生成 `K×4` 响应矩阵；
- 每档跨channel CV达标；
- 所有channel单调；
- 最小灰度间隔达标；
- 黑底、杂散和最差组合达标。

## 阶段5：不同灰度直方图与复杂图案

目标：检验公共曲线是否只在等面积校准块上成立。

依次测试：

1. 各channel灰度面积不同；
2. 边缘和细线图案；
3. 不同空间位置；
4. 从未参与训练的验证图；
5. 更复杂的多灰度图。

若校准图都不可行，应停止，不得通过增加轮数或修改前向掩盖根因。

## 阶段6：稳健性与交付

- 多随机种子；
- 相位量化；
- 小扰动敏感性；
- 最差通道稳定性；
- 原始数组与统一曝光结果归档；
- 记录损失权重、容差和失败案例；
- 冻结正式配置后再进行最终轮数。

## 推荐代码边界

```text
forward.py       只包含冻结物理前向；禁止损失代码反向依赖修改
targets.py       二值/四灰度目标与掩膜
losses.py        图案、一致性、间隔、均匀性、背景、杂散、最差项
optimize.py      autograd、Adam和训练循环
metrics.py       只读原始I_c进行验收
outputs.py       NPZ/CSV/统一曝光，不参与训练
tests/           前向回归、Parseval、损失退化和回放一致性
```

## 每阶段的停止规则

- 前向回归失败：立即停止；
- 原始强度未保存：不得验收；
- 只在逐channel归一化图上变好：判为无效；
- CV下降但灰度间隔塌缩：判为无效；
- 平均达标但最差组合超差：判为未完成；
- 需要修改物理前向才能继续：在本项目中判为不可行，另开研究项目讨论。
