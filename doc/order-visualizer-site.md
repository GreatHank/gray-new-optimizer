# 级次选择可视化网站

## 目标与范围

`visualization_tools/order_visualizer/` 提供一个完全在本地浏览器运行的交互页面，用于把一张完整图片等分为连续级次对应的切片，并同时观察二维光栅方程给出的级次中心、空气传播圆、NA 收集范围、全视场候选级次和标称 FoV。它是物理布局与映射检查工具，不执行相位优化。

## 默认方案

- channel：`9`，即 `3×3`
- 波长：`lambda=480 nm`
- 等向周期：`P_x=P_y=2000 nm`
- 连续级次：`m,n=-3…-1`
- 共同入射：`theta_i=42.7517°`、`phi_i=45°`
- 入射/输出折射率：`n_in=n_out=1`（空气）
- 数值孔径：`NA=1`
- 默认图片透明度：`34%`

这组参数与 `easy_picture` 的 3×3 推荐方案一致，页面初始结果为9/9级次中心传播且被NA收集，级次间距 `Delta_u=0.24`，标称圆形 FoV 约 `42.20°`。

## 使用方式

在项目根目录运行：

```powershell
python -m http.server 4173 --directory dist
```

然后打开 `http://127.0.0.1:4173/`：

1. 选择或拖入 PNG、JPG、WEBP、GIF、BMP 或 SVG 图片。
2. 设置波长、周期、channel 数和连续级次起点。
3. 用滑块或数字框调整共同入射极角、方位角。
4. 点击“自动居中图像”，可根据当前级次范围反算 `theta_i` 和 `phi_i`，让整组图片方格的中心落在传播圆中心。
5. 如有需要，展开高级参数调整折射率、NA 和图片透明度。
6. 查看 FoV、传播/收集数量、全视场候选级次表，或导出当前画布为 PNG。未被当前图片选中的级次仍以浅灰方格显示并可点击查看。

图片只在当前浏览器页面内读取，不发送到服务器。channel 使用下拉框选择，只提供 `4、9、16、25…400`（即 `2×2…20×20`）这些完全平方数，界面中无法选到其他数值；程序接口仍会拒绝非法 channel。

波长、周期等数值框在停止输入约180毫秒后更新，失焦或确认输入时立即更新，避免编辑多位数时用临时中间值反复重建整张图。若当前 `lambda/P` 导致全视场候选扫描范围超过2500个整数格，页面会直接提示调整参数，不会进入可能卡死浏览器的大循环，也不会静默截断候选级次。

## 图片切分与级次映射

若 `channel=g²`，原图按行优先严格等分为 `g×g`。为了让切片在物理坐标图中仍能按原方向拼回完整图片，第 `r` 行、第 `c` 列切片映射为：

```text
m = m_start + c
n = n_start + (g - 1 - r)
```

其中 `r,c` 从0开始。横轴 `m` 从左向右增大，纵轴 `n` 从下向上增大，因此原图顶行对应较大的 `n`，原图底行对应较小的 `n`。每个切片只由对应局部角谱正方形裁剪；空气传播圆和NA圆仅叠加为参考边界，不再裁掉图片。这一显示规则用于清楚确认“哪块图片位于哪个级次”，同时保证所有切片在画布上能恢复原图方向。

## 全视场候选级次

页面不再只生成当前 `g×g` 选区。对于同一组 `lambda/P` 和共同入射角，它还枚举所有整数 `(m,n)`，只要该级次对应的局部正方形角谱与空气单位圆有交集，就纳入候选池：

```text
d_x = max(|u_x| - Delta_u/2, 0)
d_y = max(|u_y| - Delta_u/2, 0)
候选条件：d_x² + d_y² <= 1
```

因此，级次中心位于圆外但方格边缘进入传播圆的情况也会显示。这与论文 Figure S9 的大视场口径一致：级次是有限面积的局部FFT角谱块，不是只有一个离散中心点。图上已选择级次带有图片和高亮边框；未选择候选级次使用浅灰边框；只有部分角谱进入空气圆的方格使用虚线。表格逐项区分“完整入圆、部分入圆、圆外”和中心的传播/NA状态。

## 物理计算

页面沿用 `coding/python/validate_diffraction_orders.py` 的固定共同入射约定：

```text
t_x = n_in sin(theta_i) cos(phi_i) + m lambda / P
t_y = n_in sin(theta_i) sin(phi_i) + n lambda / P
u_x = t_x / n_out
u_y = t_y / n_out
```

当 `sqrt(u_x²+u_y²) <= 1` 时，级次中心可传播；当它同时满足 `sqrt(t_x²+t_y²) <= NA` 时，可被给定NA收集。极角从表面法线 `+z` 量起，方位角是横向投影从 `+x` 朝 `+y` 的角度。

局部角谱级次间距为：

```text
Delta_u = lambda / (P n_out)
```

`g×g` 方阵的标称圆形 FoV 按下式报告：

```text
FoV = 2 asin(g Delta_u / 2)
```

该值只在 `g Delta_u / 2 <= 1` 时有完整物理意义；超过该范围时，页面显示“不可完整覆盖”，而不是把超界结果截断成180°。

## 参数影响

- `P` 变小或 `lambda` 变大：级次间距和FoV增大，但外围级次更容易离开传播圆。
- channel 增多：图片切片和连续级次数同时增多，名义拼接宽度增加。
- `theta_i`：改变级次点阵的共同平移量。
- `phi_i`：改变点阵平移方向。
- `n_in`：改变入射横向波矢；空气默认值为1。
- `n_out`：改变输出方向余弦和FoV；空气默认值为1。
- `NA`：限制实际可收集的级次范围，且必须满足 `0 < NA <= n_out`。
- `m_start/n_start`：整体平移所选连续整数级次，但不改变相邻级次间距。

## 自动居中

连续方阵的平均级次为：

```text
m_center = m_start + (g - 1) / 2
n_center = n_start + (g - 1) / 2
```

“自动居中图像”按钮反算共同入射横向波矢：

```text
t_ix = -m_center lambda / P
t_iy = -n_center lambda / P
theta_i = asin(sqrt(t_ix² + t_iy²) / n_in)
phi_i = atan2(t_iy, t_ix)
```

计算成功后，页面同时更新两个滑块和数字输入框。若所需横向波矢大于 `n_in`，自由空间入射无法实现该平移，页面会明确报错并保留原角度。

## 文件与验证

- `visualization_tools/order_visualizer/index.html`：页面结构和中文说明
- `visualization_tools/order_visualizer/styles.css`：响应式界面与可视化样式
- `visualization_tools/order_visualizer/app.js`：图片分割、物理计算、Canvas绘制、校验和导出

基础检查：

```powershell
node --check visualization_tools/order_visualizer/app.js
```

浏览器验证应至少覆盖：默认9-channel结果、全视场候选级次显示、圆边缘部分相交级次、有效完全平方数切换、非完全平方数报错、波长输入中间值触发扫描上限后仍可继续恢复、角度滑块/数字框联动、图片切片显示和移动端布局。

## 限制

- 页面只验证二维光栅方程层面的传播与NA收集，不评价器件效率、串扰、偏振、材料损耗、结构共振或图像解耦质量。
- 全视场候选扫描范围硬上限为2500个整数格；超出时需要增大波长、减小周期，或另行实现虚拟化/分块计算。
- 当前周期在x/y方向相同；若以后需要 `P_x != P_y`，应同时拆分横纵级次间距和FoV输出。
- 图片格式受浏览器解码能力限制；TIFF等不稳定格式应先转为PNG、JPG或WEBP。
- 导出的是当前可视化画布，不是优化器的物理重建结果。
