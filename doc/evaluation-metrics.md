# 优化结果评价指标

优化前的源图适配性评价由`coding/python/evaluate_source_image_channels.py`完成。
它把四灰度图规则切成channel，并同时报告：包含黑底的`channel_target_mean`、
只统计`85/170/255`的`foreground_gray_mean`、线条覆盖率、三档灰阶熵和二值边界密度。
其中`channel_target_mean`的跨channel CV是源图总体亮度均衡性的主指标；另外几项用于判断
亮度差异究竟来自线条多少、灰阶配比还是线条复杂度。脚本不设未经实验确认的通过阈值。

每次优化结束后，程序对原始重建强度 `I` 计算五类评价。指标不使用逐通道最大值拉伸，避免把低亮度失败通道显示成正常结果。

## 1. 结构完整程度

先计算本通道背景均值 `bg`，得到正对比度图：

```text
C(x,y) = max(I(x,y) - bg, 0)
```

为避免三个目标灰度档本身的亮度差异影响结构评价，目标区域先按对应目标灰度 `T(x,y)` 校正：

```text
C_structure(x,y) = C(x,y) / T(x,y),  x,y in target
```

背景区域保持原正对比度。再将目标所有非零灰度像素视为二值结构掩膜 `M`，计算：

```text
structure_cosine = dot(C_structure,M) / (norm(C_structure) * norm(M))
```

该值范围接近 `0–1`，越高表示能量位置越符合完整目标轮廓。它会同时受到目标外杂散能量和目标线内部缺失影响。

再以背景像素亮度的95分位 `bg_p95` 为可见阈值：

```text
foreground_coverage = count(I on target > bg_p95) / target_pixel_count
```

覆盖率越高，表示越多目标线像素明显高于绝大多数背景。结构判断同时报告余弦相似度和覆盖率，避免只形成少数高亮点却被误判为完整图形。

## 2. 灰度分级情况

对每个通道和每个灰度档计算扣除背景后的有效响应：

```text
S[c,l] = (mean(I[c] on level l) - bg[c]) / plane_mean[c]
```

首先检查：

```text
S[c,1/3] < S[c,2/3] < S[c,1]
```

`grayscale_monotonic_channels` 表示满足严格单调的通道数。然后用最高档归一化，计算实际比例与期望响应比例的均方根误差。默认期望比例为 `[1/3, 2/3, 1]`，也可由 `--desired-gray-ratios LOW MID` 改为 `[LOW, MID, 1]`：

```text
ratio_rmse[c] = RMSE(S[c,:] / S[c,1], desired_gray_ratios)
```

RMSE 越接近0，三个灰度级次比例越准确。单调通道数和比例误差共同表示“是否分级”和“分级是否正确”。

MSE 是各误差平方后的平均值，RMSE 是 `sqrt(MSE)`。二者都是越低越好；RMSE与被比较的灰度比例处于同一尺度，更容易直观解释。例如 `ratio_rmse=0.018` 表示归一化三级比例相对目标比例的典型偏差约为0.018，而不是亮度本身只有0.018。MSE/RMSE很高表示三级虽然可能保持顺序，但间隔比例偏离目标；很低则表示比例接近 `1:2:3`。

相邻灰度差值为：

```text
gap_1 = S[2/3] - S[1/3]
gap_2 = S[1] - S[2/3]
```

差值必须为正才能保持单调；差值过小会使肉眼难以分级。差值不是越大越好，因为过度拉大可能牺牲结构或最弱通道。本项目同时检查单调通道数、两个平均差值和比例RMSE。

## 3. 同灰度跨通道一致性

分别收集当前参与优化且实际包含对应灰档的通道的 `S[c,1/3]`、`S[c,2/3]` 和 `S[c,1]`，每档计算变异系数。纯黑channel不参与任何一档，只含部分灰档的channel仅参与它实际拥有的灰档：

```text
CV[l] = std(S[:,l]) / abs(mean(S[:,l]))
```

CV 越接近0，同一灰度档在不同通道中越一致。程序同时保存每档的均值、最小值和最大值，避免 CV 掩盖最弱通道。

CV是相对离散度，不代表绝对亮度。所有channel统一乘以2后，均值和标准差都乘以2，因此CV不变；如果三级共同变暗但相对离散度缩小，CV也可能下降，所以必须同时检查灰度差值、结构和固定曝光图，防止“共同变暗”的假改善。

## 4. 背景噪声均匀性

程序报告三个互补指标：

- `background_cv = std(background) / mean(background)`：像素级散斑起伏，越低越均匀。
- `background_p95_ratio = p95(background) / mean(background)`：背景热点强度，越低表示亮斑越少。
- `background_row_cv`：每行背景均值的 CV，越低表示没有明显的行方向亮度带或大尺度起伏。

像素 CV 高但逐行 CV 低，通常表示背景存在细粒度随机散斑，但没有明显的大尺度横向条纹。三项均需结合统一曝光图判断。

## 5. 前景/背景信噪分离

对每个通道计算前景均值 `mu_fg`、背景均值 `mu_bg` 和背景像素标准差
`sigma_bg`。先保留带符号的前景—背景对比噪声比：

```text
CNR = (mu_fg - mu_bg) / sigma_bg
```

SNR采用论文口径，把目标前景区域的平均强度作为`mu_signal`，把背景区域的强度标准差
作为`sigma_noise`：

```text
SNR_dB = 20 log10(mu_signal / sigma_noise)
       = 20 log10(mu_fg / sigma_bg)
```

这不是相干光场的探测器噪声SNR，也不包含散粒噪声、读出噪声或实验暗噪声；
它只评价当前数值重建中，前景平均强度相对于背景散斑起伏有多大。`CNR<=0`
仍表示前景均值不高于背景均值；论文SNR的`0 dB`表示前景平均强度等于一个背景
标准差。CNR与论文SNR是两个独立指标，不能互换。二者均不随所有channel共同曝光倍率
改变，不能代替结构、覆盖率或跨通道CV。

需要把该评价直接用于训练时，可设置`--foreground-background-cnr-weight W`。优化器对每个
通道使用：

```text
L_CNR = softplus(1 - CNR)
```

再取跨通道平均并乘以权重`W`。该形式在CNR低于1时给出较强梯度，CNR提高后平滑衰减；
它同时鼓励提高前景—背景均值差和降低背景标准差，而且对全部强度共同缩放不敏感。
它不是实验探测器SNR模型，也不能单独保证结构或灰度一致性，实际运行应同时检查结构、
覆盖率和三档CV。`W=0`保持此前训练行为不变。

需要把论文SNR作为逐通道硬验收门槛时，使用
`--paper-snr-weight W --paper-snr-target-db 15`。15 dB等价于
`mu_fg/sigma_bg >= 10^(15/20) = 5.6234`。每个通道的可微短缺损失为：

```text
r = mu_fg / sigma_bg
L_i = max(0, r_target - r) / r_target
L_paper_SNR = mean(L_i) + max(L_i)
```

使用线性hinge是为了让未达标通道在接近门槛时仍保持直接梯度；`max(L_i)`专门推动当前
最差通道，因此验收看`SNR_min > 15 dB`，不能用均值代替。
`--paper-snr-weight`默认值为0，不改变旧命令的训练行为。该门槛仍不保证结构、覆盖率或
三档跨通道CV；这些指标必须单独报告。

2026-09-06以前生成的CSV把`20log10(abs(CNR))`写入SNR列，属于旧口径；其数值用于当时
各阶段相对比较，但不能与新论文口径直接混用。已有NPZ可用
`coding/python/evaluate_saved_results.py`重新计算，无需重新训练。

## 输出文件

- `evaluation_channel_metrics.csv`：逐通道详细指标。
- `evaluation_summary.csv`：所有通道的均值、最差值和三档跨通道 CV。
- `coding/python/evaluate_saved_results.py`：不重新训练，给已有NPZ补算最新评价，并额外输出逐级次`snr_channel_metrics.csv`和`snr_by_channel.png`。
- 终端在每次优化结束时自动打印五项摘要。

当前不设置未经验证的统一“通过阈值”。后续实验使用相同指标横向比较，并结合统一曝光图判断结构与背景是否可接受。

## 当前36通道候选的读法

`output/geometric_network_36_cv_gap_stage2_500` 的三档CV为 `0.009/0.049/0.078`，比前一候选降低约 `82%/58%/48%`；比例RMSE由 `0.0327` 降至 `0.0181`，说明跨通道一致性和三级比例都明显改善。两个平均相邻差值仍为 `0.460/0.485`，36/36通道保持严格单调，因此CV改善不是由三级合并造成。

结构余弦均值由 `0.403` 降至 `0.383`（约下降5%），平均覆盖率由 `0.223` 降至 `0.198`（约下降11%），属于本轮CV优先的代价；最差覆盖率反而由 `0.122` 提高到 `0.147`。背景CV和逐行CV基本不变。最终显示使用一个作用于全部channel的公共 `2×` 入射光强倍率，它只增加绝对亮度，不改变上述相对指标。
