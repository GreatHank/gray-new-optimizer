# 优化结果评价指标

每次优化结束后，程序对原始重建强度 `I` 计算四类评价。指标不使用逐通道最大值拉伸，避免把低亮度失败通道显示成正常结果。

## 1. 结构完整程度

先计算本通道背景均值 `bg`，得到正对比度图：

```text
C(x,y) = max(I(x,y) - bg, 0)
```

为避免三个目标灰度档本身的亮度差异影响结构评价，目标区域先按对应目标灰度 `T(x,y)` 校正：

```text
C_structure(x,y) = C(x,y) / T(x,y),  x,y in target
```

背景区域保持原正对比度。再将目标所有非零灰度像素视为二值结构掩膜 `M`，计算：

```text
structure_cosine = dot(C_structure,M) / (norm(C_structure) * norm(M))
```

该值范围接近 `0–1`，越高表示能量位置越符合完整目标轮廓。它会同时受到目标外杂散能量和目标线内部缺失影响。

再以背景像素亮度的95分位 `bg_p95` 为可见阈值：

```text
foreground_coverage = count(I on target > bg_p95) / target_pixel_count
```

覆盖率越高，表示越多目标线像素明显高于绝大多数背景。结构判断同时报告余弦相似度和覆盖率，避免只形成少数高亮点却被误判为完整图形。

## 2. 灰度分级情况

对每个通道和每个灰度档计算扣除背景后的有效响应：

```text
S[c,l] = (mean(I[c] on level l) - bg[c]) / plane_mean[c]
```

首先检查：

```text
S[c,1/3] < S[c,2/3] < S[c,1]
```

`grayscale_monotonic_channels` 表示满足严格单调的通道数。然后用最高档归一化，计算实际比例与 `[1/3, 2/3, 1]` 的均方根误差：

```text
ratio_rmse[c] = RMSE(S[c,:] / S[c,1], [1/3,2/3,1])
```

RMSE 越接近0，三个灰度级次比例越准确。单调通道数和比例误差共同表示“是否分级”和“分级是否正确”。

MSE 是各误差平方后的平均值，RMSE 是 `sqrt(MSE)`。二者都是越低越好；RMSE与被比较的灰度比例处于同一尺度，更容易直观解释。例如 `ratio_rmse=0.018` 表示归一化三级比例相对目标比例的典型偏差约为0.018，而不是亮度本身只有0.018。MSE/RMSE很高表示三级虽然可能保持顺序，但间隔比例偏离目标；很低则表示比例接近 `1:2:3`。

相邻灰度差值为：

```text
gap_1 = S[2/3] - S[1/3]
gap_2 = S[1] - S[2/3]
```

差值必须为正才能保持单调；差值过小会使肉眼难以分级。差值不是越大越好，因为过度拉大可能牺牲结构或最弱通道。本项目同时检查单调通道数、两个平均差值和比例RMSE。

## 3. 同灰度跨通道一致性

分别收集当前参与优化的全部通道的 `S[c,1/3]`、`S[c,2/3]` 和 `S[c,1]`，每档计算变异系数：

```text
CV[l] = std(S[:,l]) / abs(mean(S[:,l]))
```

CV 越接近0，同一灰度档在不同通道中越一致。程序同时保存每档的均值、最小值和最大值，避免 CV 掩盖最弱通道。

CV是相对离散度，不代表绝对亮度。所有channel统一乘以2后，均值和标准差都乘以2，因此CV不变；如果三级共同变暗但相对离散度缩小，CV也可能下降，所以必须同时检查灰度差值、结构和固定曝光图，防止“共同变暗”的假改善。

## 4. 背景噪声均匀性

程序报告三个互补指标：

- `background_cv = std(background) / mean(background)`：像素级散斑起伏，越低越均匀。
- `background_p95_ratio = p95(background) / mean(background)`：背景热点强度，越低表示亮斑越少。
- `background_row_cv`：每行背景均值的 CV，越低表示没有明显的行方向亮度带或大尺度起伏。

像素 CV 高但逐行 CV 低，通常表示背景存在细粒度随机散斑，但没有明显的大尺度横向条纹。三项均需结合统一曝光图判断。

## 输出文件

- `evaluation_channel_metrics.csv`：逐通道详细指标。
- `evaluation_summary.csv`：所有通道的均值、最差值和三档跨通道 CV。
- 终端在每次优化结束时自动打印四项摘要。

当前不设置未经验证的统一“通过阈值”。后续实验使用相同指标横向比较，并结合统一曝光图判断结构与背景是否可接受。

## 当前36通道候选的读法

`output/geometric_network_36_cv_gap_stage2_500` 的三档CV为 `0.009/0.049/0.078`，比前一候选降低约 `82%/58%/48%`；比例RMSE由 `0.0327` 降至 `0.0181`，说明跨通道一致性和三级比例都明显改善。两个平均相邻差值仍为 `0.460/0.485`，36/36通道保持严格单调，因此CV改善不是由三级合并造成。

结构余弦均值由 `0.403` 降至 `0.383`（约下降5%），平均覆盖率由 `0.223` 降至 `0.198`（约下降11%），属于本轮CV优先的代价；最差覆盖率反而由 `0.122` 提高到 `0.147`。背景CV和逐行CV基本不变。最终显示使用一个作用于全部channel的公共 `2×` 入射光强倍率，它只增加绝对亮度，不改变上述相对指标。
