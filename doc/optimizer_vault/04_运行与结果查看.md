# 运行与结果查看

上一步：[[03_损失函数与评价指标]]　下一步：[[05_项目结构与代码索引]]。

主配置为 configs/circle-ocean-3x3-p800-500-strict9.json。以下命令都在项目根目录执行：

```powershell
python -m coding.targets.prepare --config configs/circle-ocean-3x3-p800-500-strict9.json
python -m coding.geometry.preflight --config configs/circle-ocean-3x3-p800-500-strict9.json
python -m coding.optimization.run --config configs/circle-ocean-3x3-p800-500-strict9.json --output-dir output/data/my-ocean-25000
python -m coding.results.report --result-dirs output/data/my-ocean-25000 --output-dir output/data/my-ocean-report
python -m pytest
```

目标已存在时跳过第一条命令。默认 Adam 连续更新 25000 次、lr=0.001、seed=43。示例阵列为 500×500，所选级次共用三张参数图，同灰度一致权重为 1。

## 可调参数

| 参数 | 含义 |
|---|---|
| target.source | 原始图片路径 |
| target.tile_size | 每个目标块和共享相位阵列的边长 |
| target.grid_size | 方形级次网格边长 |
| target.order_m_start/order_n_start | 级次起点 |
| target.resized_size/canvas_offset | 完整源图的大小与画布位置，禁止裁断 |
| target.excluded_canvas_positions | 不选的网格行列，必须为纯黑目标 |
| optimizer.mat_file | 已生成的固定目标 |
| epochs、lr、seed | 更新次数、学习率、随机种子 |
| optimizer_name | adam 或 lbfgs，前向与损失相同 |
| gray_consistency_weight | 同灰度跨级次原始均值一致项权重，默认 0 |
| initial_results | 恢复三张相位，重新建立优化器 |
| device | auto/cpu/cuda |

改变目标、级次或阵列尺寸后，生成到新目录并更新 mat_file。所有目标与运行目录禁止覆盖。L-BFGS 线搜索可能增加求值次数，应按 optimizer_work 比较预算。

## 查看哪些文件

平时只看 output/runs 的图片分类目录：每次优化自动生成一张最终 target/效果对比 PNG。下文的 output/data 是原始优化数据与可选详细分析，用于续跑和核查。

乌龟严格九级次的数据为 output/data/circle-ocean-3x3-p800-500-strict9-adam-25000。4×4及不同迭代预算分别使用独立配置与数据目录；具体数据与限制见当前实验。1×/2×只改变展示，不改raw或统计窗口。当前无自动制造导出、中途checkpoint或提前停止。
