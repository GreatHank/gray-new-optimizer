# 从原图到固定目标

返回 [[00_开始阅读]]；下一步 [[02_一轮优化与梯度更新]]。

以下以 input/tiger_detailed.png 为例；圆形星空、乌龟和山涧使用各自的源圆映射配置，完整目标与结果见 [当前实验](../experiments.md)。整图统一缩放、放入黑画布，不裁内容、不逐块改亮度。保留 256 档，T=k/255，黑背景为 k=0。

| 设置 | 3×3 | 4×4 |
|---|---|---|
| 配置 | tiger-3x3-p800-500.json | tiger-4x4-p1050-500.json |
| 源图缩放 | 1402×1402 | 1840×1840 |
| 画布 / 位置 (x,y) | 1500×1500 / (48,85) | 2000×2000 / (79,127) |
| 级次 | m,n=-2…0，共 9 个 | m,n=-2…1，共 16 个 |
| 周期 / 极角 / 方位角 | 800 nm / 70.1276° / 45° | 1050 nm / 20.9938° / 45° |
| 00 的通道号 | 3 | 7 |

每个目标块为 500×500；另有一套 500×500 的共享相位阵列。每个级次使用整个阵列，目标切块不等于把纳米砖按通道拆分。

级次按行优先，m 向右、n 向上。边长 G、行列从 0 计数时 m=m_start+c，n=n_start+G-1-r。4×4 保留全部四角。

| MAT 字段 | 含义 |
|---|---|
| bw_all | 按通道顺序排列的浮点目标 |
| order_pairs | 显式 (m,n) |
| grid_positions | (m-m_start,n-n_start) |
| canvas_positions | 拼图行列 (r,c) |
| gray_level_count | 灰度档数 |

两组 λ=532 nm、NA=1；老虎图实际非黑轮廓均完整入圆，最外端接近边界。3×3 的 9/9 个中心传播，1 个方格完整、8 个部分可见；4×4 的 12/16 个中心传播，4 个完整、12 个部分可见。中心、方格角域与老虎图支撑不能混为一谈。

几何只把 FFT 频率映射为出射方向；当前没有角度相关单元响应。固定级次和目标时，仅改入射角不会改变标量 FFT 图像优化路径。
