# 多级次共享相位优化器

当前对老虎、圆形星空、乌龟和山涧按所选级次优化，默认使用乌龟严格3×3，流程只需记住四步：

1. 一套共享阵列，每个位置有 dx、dy、PP 三个参数；500×500 为 750000 个标量。
2. 每个级次共用这三张图，计算 Φ=m dx+n dy+PP，再经 FFT 的模平方得到图像。
3. 将所选级次的图与固定目标比较（严格 3×3 为 9 个，4×4 为 16 个）：共同尺度 RMSE 加同灰度亮度一致项。
4. Adam 更新参数，重复配置指定的次数；热启动只继承三张相位图。

3×3 的 P=800 nm、θ=70.1276°；4×4 的 P=1050 nm、θ=20.9938°。两组 λ=532 nm、φ=45°。每张完整源图统一缩放、补黑背景，在近似相同角域内完整入圆。

级次共享阵列，不能各自任意指定相位。00 的相位是 PP，可以编码。4×4 采样更细，也需要计算更多 FFT；画质与 SNR 见 [当前实验](../experiments.md)。
