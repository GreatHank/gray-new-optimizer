# 项目结构与代码索引

上一步：[[04_运行与结果查看]]　返回：[[00_开始阅读]]

## 目录

| 目录 | 内容 |
|---|---|
| coding/targets | 原图准备、固定目标与级次映射 |
| coding/optimization | 共享 dx/dy/PP 前向、损失与优化循环 |
| coding/geometry | 共同入射、传播圆与实际目标支撑检查 |
| coding/results | 原始数据、指标、统一曝光报告与比较 |
| coding/tests | 独立数值参考与流程回归 |
| configs | 当前 PP 实验配置、smoke 与 selected-results.json；早期 PP 配置不属于当前入口 |
| input | 原始输入 |
| output/targets | 派生目标 |
| output/runs | 按图片分类的最终 target/效果对比图 |
| output/data | 优化相位、指标、完整报告与比较 |
| doc/optimizer_vault | 本阅读库 |
| visualization_tools/order_visualizer | 独立级次几何预览网页 |

配置包括老虎的 3×3/4×4、圆形图的16级次、乌龟与山涧的严格九级次，阵列均为500×500。每个配置对应独立目标和 run id。

## 代码阅读顺序

| 文件 | 职责 |
|---|---|
| coding/targets/prepare.py | 完整原图缩放、圆域映射与目标标签 |
| coding/optimization/data.py | MAT、级次顺序和灰度标签 |
| coding/geometry/preflight.py | 几何通过条件与部分可见范围 |
| coding/optimization/model.py | 共享相位 FFT、共同尺度 RMSE、同灰度一致项 |
| coding/optimization/run.py | 准备、梯度循环、最终重算与保存 |
| coding/optimization/diagnostics.py | 无梯度的逐轮观测 |
| coding/results/storage.py | PP 结果读写与三张相位热启动 |
| coding/results/metrics.py | 原始亮度、有效响应、SNR/CNR 与能量占比 |
| coding/results/publish.py | 按图片分类，发布一张最终 target/效果对比图 |
| coding/results/report.py | 可选完整报告、统一曝光与独立前向核查 |
| coding/results/compare_grids.py | 不同级次布局在共同角域中的比较 |
| coding/results/compare_arrays.py | 不同阵列尺寸与迭代预算的比较 |

流程为配置 → 目标 MAT → 几何预检 → 优化 → 原始结果 → 报告与比较。几何检查不参与图像损失的反向传播，报告不会继续优化相位。

## 验证与修改边界

pytest.ini 指向 coding/tests。核心测试使用独立 NumPy、Parseval、解析梯度或有限差分；另核对目标放置、固定统计窗口、无损标签、三张相位往返以及缺少 PP 的结果拒绝读取。

轮数、学习率和种子试验只改配置并使用新 run id。前向修改需要独立参考与 Parseval 回归；不能添加逐通道增益或裁切窗口制造改善。运行与证据边界见 [运行说明](../usage.md)、[有效约束](../requirements.md) 和 [物理依据](../physics.md)。
