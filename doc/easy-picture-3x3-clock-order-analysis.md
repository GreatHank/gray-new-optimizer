# easy_picture.png 的3×3“钟表式”级次分析

本次分析针对 `input/easy_picture.png`，采用固定参数 `lambda=480 nm`、`P_x=P_y=2000 nm`、`Delta_u=0.24`、`n_in=n_out=1`、`NA=1`。图像先整体变换，再严格等分为3×3；没有交换单独图块。这里的3×3表示一幅完整全局图像被相邻局部角谱区域拼接，不是9幅重复完整图。

## 推荐方案的传播方向

推荐方阵为 `m=-3…-1、n=-3…-1`，`u_ix=0.48、u_iy=0.48`，所以 `theta_i=42.75170°、phi_i=45°`。9个级次的 `(u_x,u_y)`、`theta`、`phi` 为：

```text
(-3,-3): (-0.24,-0.24), theta=19.8410°, phi=-135°
(-3,-2): (-0.24, 0.00), theta=13.8865°, phi=180°
(-3,-1): (-0.24, 0.24), theta=19.8410°, phi=135°
(-2,-3): ( 0.00,-0.24), theta=13.8865°, phi=-90°
(-2,-2): ( 0.00, 0.00), theta=0°,       phi=0°
(-2,-1): ( 0.00, 0.24), theta=13.8865°, phi=90°
(-1,-3): ( 0.24,-0.24), theta=19.8410°, phi=-45°
(-1,-2): ( 0.24, 0.00), theta=13.8865°, phi=0°
(-1,-1): ( 0.24, 0.24), theta=19.8410°, phi=45°
```

9/9级次中心传播并被NA=1收集。最差中心空气锥余量为 `1-max(sqrt(u_x²+u_y²))=0.66059`。把每个级次按宽度 `Delta_u` 的局部角谱方格处理时，完整3×3方格的最小边界余量为 `0.49088`；这与“中心可传播”不同，后者不能单独证明每个完整局部方格都在圆内。

## FoV与论文对照

按用户指定口径，完整3×3角谱宽度为 `3Delta_u=0.72`，标称圆形FoV取 `2 asin(3Delta_u/2)`，本项目固定参数报告约 `42.18116°`（直接数值计算为约42.20°，保留用户指定值用于对照）。不能把论文 `P=1000 nm` 的实验87°写成当前 `P=2000 nm` 结果。论文对照为：`P=1000 nm、lambda=480 nm` 时理论完整3×3约92.11°；Sample 3实际采用约87°圆形区域，论文指出平面投影边缘约有25%几何畸变。

## 目标MAT与复核

推荐目标已生成于 `output/easy_picture_3x3_order_analysis/easy_picture_3x3_target.mat`：`bw_all` shape 为 `9×500×500`，由identity后的整幅图最近邻切块得到；灰度映射沿用项目规则（输入灰度按项目既有目标流程映射），`grid_positions` 为行优先0…2坐标，`pairMat` 逐项为推荐9个级次。分析脚本为 `coding/python/analyze_easy_picture_3x3.py`。

该方案与Figure S9相同点：一幅完整图像跨连续3×3相邻级次区域拼接，并以全局角谱/圆形传播域定义视场。不同点：Figure S9没有公开这9个区域的具体整数 `(m,n)`，本报告的级次是基于当前固定参数和纯 `dx/dy` 迂回相位的工程候选；没有声称复现Figure S2，也没有PB旋转相位，因此不能宣称实现近180°共轭级次独立编码。

阶段A末尾损失仍下降，因此继续到累计1000轮。阶段B只提高 Ch6、Ch8、Ch9 原有主结构损失权重到3；其中 Ch6、Ch8 是高复杂区域，Ch9 `(-1,-1)` 是当时结构、覆盖率和SNR共同最差通道且属于三成员倍频组。阶段C至E依次加入整体亮度CV、三档跨通道CV和背景方差/9×9热点约束。阶段F先以权重20加入论文线性hinge；随后为测试极限，移除CV和背景辅助项、把hinge权重提高到100并延长3500轮。

最终极限解的9个原始 SNR 全部严格大于15 dB。最差为 Ch9 `(-1,-1)` 的 `15.002610717607 dB`，不是把14.99 dB四舍五入为15 dB。该级次与中心 Ch5 `(-2,-2)`、Ch1 `(-3,-3)` 同属倍频组；最终三者SNR分别约15.0026、15.0110、15.0471 dB，因此倍频耦合仍影响最弱通道，但本次没有阻止数值门槛通过。

视觉上两种结果都形成完整、可辨认的圆形场景、轮廓和内部结构。平衡解实际三档相对响应约为 `0.389:0.709:1`；纯SNR极限解变为约 `0.554:0.788:1`。极限解虽降低背景噪声并提高覆盖率，但结构均值下降约9.6%，比例 RMSE max 增至0.2654，最高灰档CV略超过0.1。因此当前应同时保留：阶段F作为平衡可用解，最终3500轮结果作为满足论文SNR门槛的纯SNR极限解。

当前级次组合值得保留：9/9传播/收集、无零级、无共轭对、最复杂3块均映射到无倍频级次，且在固定共享自由度下已证明数值上可达到全部通道SNR门槛。继续增加轮数不值得：最终hinge已归零附近，最后200轮总损失只从约15.55降至15.42，SNR集中在15.00附近；更多轮数预计主要优化主损失或在门槛附近振荡，不能恢复已损失的灰度比例。若需要同时保持平衡解的灰度/结构并获得明显高于15 dB的裕量，需要增加真实自由度，例如独立相位/振幅控制、PB相位或重新分配/减少共享通道，而不是公共曝光倍率。
