灰度优化损失速查

四个目标、四组职责；物理前向保持不变。

目标主要损失防止的问题
结构完整能量分布 KL + 逐像素最低响应缺线、局部亮点代替完整轮廓
灰度分级每通道灰度比例损失三档挤在一起或偏离 1:2:3
同灰度一致固定 Q 档位损失 + 同档 CV 损失不同通道亮度差异、整体变暗作弊
背景均匀背景方差 + 热点惩罚亮斑和成块噪声
S[c,l] = (mean(I[c] on level l) - bg[c]) / plane_mean[c]
CV[l] = std(S[:,l]) / abs(mean(S[:,l]))
公共目标 = Q × [1/3, 2/3, 1]

读数方向：结构相似度和覆盖率越高越好；比例 RMSE、三档 CV 和背景指标越低越好。
