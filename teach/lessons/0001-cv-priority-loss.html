CV优先灰度损失：为什么有效

目标：保持完整水果轮廓和 1:2:3 灰度，同时让23个通道的相同灰度尽量一致。

1. 先分清两个“一致”

通道内灰度正确：同一通道中满足 S1/3 < S2/3 < S1，比例接近 1/3:2/3:1。

跨通道同灰度一致：例如23个通道的 S1 都接近同一个绝对值。前者正确，不代表后者自动正确。

2. 当前联合损失的分工

结构
能量分布 + 逐像素最低响应
灰度
每通道比例接近 1:2:3
一致性
同档响应靠近公共目标
背景
低权重抑制明显恶化
L = Lstructure + λgray·Lgray + λlevel·Llevel + λcross·Lcross + λbg·Lbg

本轮把 λcross 提高到CV优先级，并固定 Q=9.198383。固定Q的作用是：通道只能真正向共同亮度靠拢，不能让所有通道一起变暗来获得虚假的低CV。

3. 最终结果怎么读

评价最终值结论
结构相似度 mean/min0.771 / 0.725轮廓完整
前景覆盖率 mean/min98.7% / 95.8%缺线较少
灰度单调与比例 RMSE23/23，0.0077分级优秀
三档跨通道 CV0.026 / 0.043 / 0.050一致性显著增强
背景像素 CV0.949保持可接受
核心结论：CV从约0.14降到0.03–0.05，不是靠逐通道增益或显示拉伸，而是通过固定公共亮度目标，直接改变共享相位变量产生的原始强度。
