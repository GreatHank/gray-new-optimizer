# 球面图像观测台

双击 `index.html`，或双击 `打开球面观测台.cmd`。无需安装依赖或联网，浏览器需支持 WebGL。点击“载入武大黑天穹顶”查看内置示例。

- **沉浸环顾**（默认）：相机固定在底面圆心，使用常规透视观察建筑。拖动转头、抬头；滚轮调整视角大小。“头顶”查看中央校徽，“视角复位”恢复正面建筑。
- **全景仰视**：从底面圆心以 180° 等距鱼眼一次显示整个穹顶。广角画面会弯曲周围建筑；检查建筑比例时使用沉浸环顾。
- **穹顶外观**：从外部观察半球，拖动旋转、滚轮缩放。
- **大屏观赏**：只显示观察画面；点击“退出大屏”或按 Esc 返回设置。
- 支持自动环绕、经纬参考线、方向键转头、Home 复位及保存当前视角 PNG。导出标注视角、映射方式和统一显示尺度。

## 素材与映射

“穹顶全景贴图”使用等角度圆盘。圆心对应头顶，圆周对应地平线；设像素距圆心为 `r`，圆半径为 `R`，穹顶覆盖角为 `F`，球面极角为：

```text
polar = r / R * F / 2
```

建筑底部朝圆周，屋顶朝圆心。武大示例的黑色天空、灰度建筑和中央小校徽来自贴图，页面不额外绘制或拉伸建筑。示例内嵌于 `campus-example.js`，双击页面也能载入，不依赖预览服务器。

圆形衍射效果图应选择“衍射圆图”，保留项目方向余弦坐标。像素中心 `(px, py)`、选定圆心 `(cx, cy)`、圆半径 `R` 和覆盖角 `F` 对应：

```text
x = (px - cx) / R * sin(F/2)
y = (cy - py) / R * sin(F/2)
z = sqrt(1 - x² - y²)
```

展示时旋转为世界坐标 `(X,Y,Z)=(x,z,-y)`。两种素材均满足：圆心为头顶 `+Y`，图像上方为地面方向 `-Z`，右方为 `+X`。默认 `F=180°`，较小覆盖角对应头顶球冠。

图片含白边、标题或左右对比图时，在平面参考图上点击所需圆心，并在“调整原图圆形区域”中设置像素半径。源圆超出原图时，缺失部分显示斜纹；工具不会自动判断标题、边框或哪一侧是效果图。

图像 RGB 保持 1×，无自动曝光、通道增益或光照明暗。经纬线默认关闭。这里只做几何展示，不重算 FFT、衍射、SNR 或效率。

## 武大示例

当前素材保留校门、礼堂、老图书馆、低层校园建筑、拱门建筑和万林艺术博物馆，去掉人物、乐器与风景背景。六张 1254×1254 透明底视图各包含一栋建筑，透明部分合成纯黑；部分天空增加少量灰度飞鸟与淡云。六栋建筑分别位于 0°、60°、120°、180°、240°、300°，每栋按独立 60° 常规透视视图进行球面重投影，再编码为 4096×4096 单通道灰度角度圆盘，建筑底部朝外。保留完整 8-bit 灰度，不量化成四灰度。中央标准校徽直径占整图 20%。输出尺寸增加不代表源图细节增加。成图按用户要求保存在 `input/`，尚未进行级次切分或相位优化。

- 当前成图：`input/whu_six_buildings_dome_gray_4096_v6_20261003.png`
- 原插画与灰度版本：`input/whu_illustration_reference_20261003.jpg`、`input/whu_illustration_gray_20261003.png`
- 建筑源视图、生成提示词、投影参数、编码脚本和浏览器实测截图：`output/data/whu_dome_v6_20261003/`；图书馆与博物馆源视图由其中的配置引用 `output/data/whu_dome_v5_20261003/`。

从项目根目录运行逻辑与几何检查：

```powershell
node --test visualization_tools/spherical_viewer/tests/viewer.test.cjs
```

这些检查覆盖三种相机、视场、图像方向、素材映射与交互状态。实际 WebGL 编译、显示与文件选择需在浏览器中验证。
